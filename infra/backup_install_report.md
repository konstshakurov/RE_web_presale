## 3. Отклонения от инструкции

1. **CRLF в доставке.** `git archive` на машине с системным `core.autocrlf=true` выдал LF→CRLF во всех 23 файлах (в репозитории LF). Исправлено на ВМ `sed -i 's/\r$//'` по инструкции задачи («при CRLF: sed…»), повторный grep чистый. На будущее: собирать архив с `git -c core.autocrlf=false archive …`.
2. **sudo без NOPASSWD.** sudo-команды шагов 2, 5, 6.1 и 6.9 выполнял владелец через `ssh -t` по заранее подготовленным агентом скриптам в `/tmp` (содержимое — ровно команды из задачи; скрипты удалялись после выполнения). Пароль sudo в чат/файлы/командные строки не попадал.
