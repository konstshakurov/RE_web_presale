# KON-92 — закреплённая шапка: один вариант + «как сейчас»

Формат по `ui_design` (точечная правка): «как сейчас» и один вариант.
Прототип: `prototype.html` (переключатели в чёрной полосе сверху: «как сейчас» / «после» / «после + модальное окно»).

| Файл | Что |
|---|---|
| `now_{dark,light}_1280.png` | как сейчас: страница прокручена на 420px — шапки нет |
| `pinned_{dark,light}_1280.png` | после: та же прокрутка — шапка на месте |
| `pinned_modal_{dark,light}_1280.png` | после: модальное окно поверх шапки (затемняет и её) |

## Идея
Шапка `position: sticky; top: 0; z-index: 5` — остаётся первым блоком в потоке, прокручивается только содержимое под ней. Одно правило CSS на `.topbar`.

## Плюсы
Минимальное изменение, высота и вид шапки прежние, отдельный контейнер прокрутки не нужен (нативная полоса прокрутки страницы остаётся), модалки (`z-index: 10`) остаются поверх, работает с историей/якорями браузера.

## Минусы
Баннер Jira остаётся в потоке и уходит за шапку при прокрутке (см. рекомендацию).

## Цена для Dev
~1 SP: правка `styles.css` (`.topbar`, `html { scroll-padding-top: 56px }`), проверка 4 разделов и модалок; новых компонентов и API нет.

## Рекомендации UX
1. **Закрепляется только шапка.** Баннер «Работа с Jira недоступна» — в потоке: он высокий (с формой пароля, на 1024 переносится в 2–3 строки), закреплённый съедал бы до трети экрана при высоте 400–700px. При вводе пароля пользователь и так на верху страницы; состояние Jira дублируется штампом «актуально на».
2. **Модальные окна поверх шапки** (как сейчас: backdrop затемняет и шапку).
3. **`scroll-padding-top: 56px` на `html`**, чтобы Tab-фокус и прокрутка к элементу не прятали элемент под шапкой.
4. Заголовки таблиц не закрепляем (отдельный CR при необходимости).

## Открытые вопросы владельцу
1. Баннер Jira — в потоке (рекомендую) или закреплять вместе с шапкой?
2. Нужна ли тонкая нижняя граница/тень у закреплённой шапки? Сейчас шапка тёмная на любом фоне, граница не требуется; рекомендую без неё (нет нового токена).
