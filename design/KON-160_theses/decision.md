# KON-160 — тезисы правил клиента из комментариев эпика: решение по UI

- Статус: **approved** | 10.11.2026 | утвердил: владелец (чат OpenCode, выбор «B»).
- Варианты: A (источники всегда видимы — прототип `variant_a.html`), **B (выбран)** —
  `variant_b.html`: источники скрыты, открываются по клику на тезис, справа бейдж с
  числом источников; конфликт полевым правилам — красная рамка и бейдж внутри тезиса.
- Спецификация: REW-28 (п. 4 «Место вывода»), BF-01.
- Схема pp. 1–5 (сбор/кэш/LLM/место вывода/API) — approved 05.11.2026 (чат OpenCode).

## Экранные элементы (вариант B)

1. Заголовок блока: «Правила из комментариев эпика» (+ бейдж «Обновляется…» при
   `regenerating`; подсказка асинхронного пересчёта).
2. Тезис — карточка-кнопка: слева текст тезиса (+ бейдж «противоречит полевым
   правилам» для конфликтов), справа — число источников («1 источник/источника/источников»).
   Клик по карточке раскрывает/скрывает блок «Источники: <автор, дата, ссылка в Jira> …»
   (`aria-expanded`, границы подсвечиваются).
3. Без источников — бейдж числа не показывается (раскрывать нечего).
4. Подпись: «Сгенерировано LLM (провайдер), дата; проверяйте по источникам».
5. Пустой эпик — нейтральная подпись «Правил из комментариев нет: клиент ещё не писал в эпик».

## Критерии приёмки QA (обе темы, 1280/1024)

1. Тезисы открываются кликом: источники (автор, дата, ссылка на комментарий в Jira) показываются
   только при раскрытии; бейдж числа источников справа; `aria-expanded` корректен.
2. Склонение числа: 1 источник / 2 источника / 5 источников; без источников — бейдж не выводится.
3. Конфликт — красная рамка + бейдж; заголовок с «Обновляется…» при `regenerating`; пусто — подпись из п. 5.
4. Повторное открытие блока не дёргает LLM без изменения hash (кэш остаётся).

## Реализация

- Frontend: `frontend/src/components/ClientRules.tsx` (компонент `ThesisItem`, скрытые источники)
  + стили `.theses__*` в `styles.css`; тест `frontend/src/test/clientRules.test.tsx`.
- Backend без изменений (сбор/кэш/LLM по pp. 1–5, деплой 09.11.2026).
