## Формулировка

> _Формулировка: «Система ДОЛЖНА [действие]...»_

Система ДОЛЖНА позволять повторно отправить назначение на уже назначенную потребность: предыдущее назначение заменяется, если Jira допускает изменение в текущем статусе; побеждает последний отправивший. При отказе Jira пользователь ДОЛЖЕН видеть причину отказа, введённые данные НЕ ДОЛЖНЫ теряться.

## Обоснование

Допускает исправление ошибочного назначения.
