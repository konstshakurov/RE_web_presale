## Формулировка

> _Формулировка: «Система ДОЛЖНА [действие]...»_

Система ДОЛЖНА запрашивать у Jira допустимые переходы из текущего статуса потребности (вместе с обязательными полями) и показывать их пользователю. Система НЕ ДОЛЖНА вводить собственных ограничений на операции: права определяются правами пользователя в Jira. Отказы Jira (403 и др.) показываются как есть.

## Обоснование

Решение по ISS-002: права = права пользователя в Jira. Полный граф workflow через REST недоступен.

## Ограничения и допущения

Переходы только из текущего статуса задачи; запись — этап 2.
