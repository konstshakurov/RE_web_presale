## Общая информация

| Атрибут | Значение |
|---------|----------|
| Актор (primary) | РН / РО / Presale-менеджер |
| Акторы (secondary) | LLM |
| Предусловие | Выбраны потребность и сотрудник; шаблон клиента есть в потребности или может быть загружен. |
| Постусловие | Создано CV типа «по шаблону клиента», привязанное к сотруднику и клиенту. |
| Триггер | Пользователь выбирает «Сделать CV по шаблону». |

## Основной сценарий (Happy Path)

1. Система проверяет, не создавалось ли CV для этой пары сотрудник/клиент.
2. Система запрашивает подтверждение: какой файл шаблона и какое корпоративное CV использовать.
3. Пользователь подтверждает или загружает недостающий файл.
4. Пользователь выбирает модель (по умолчанию внутренняя).
5. Пользователь даёт команду «адаптируй».
6. Система передаёт в LLM шаблон и корпоративное CV и получает результат.
7. Система показывает результат; пользователь сохраняет его как CV по шаблону.

## Альтернативные сценарии

1а. Такое CV уже создавалось — система показывает его; пользователь использует его или создаёт заново.

## Сценарии исключений

6а. LLM не ответила за 120 с — система сообщает о таймауте.
