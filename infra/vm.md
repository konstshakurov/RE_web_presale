### Расхождений с заявкой нет
Железо соответствует или превышает запрошенное. Следить за свободным местом на диске. Хранилища для бэкапов вне ВМ у Support нет: бэкапы локальные + еженедельная ручная выгрузка дампа владельцем; риск потери ВМ = потеря локальных бэкапов принят владельцем (политика — `infra/vm_setup.md`, раздел 6).

## Оценка объёма данных (владелец, 20.10.2026)

| Составляющая | Оценка |
|---|---|
| Сотрудники | 100 |
| CV | 1 CV = 40–100 КБ, минимум 5 CV на сотрудника → не более ~50 МБ |
| Дополнительные файлы | по ~1 МБ у части сотрудников; верхняя оценка всех файлов не более ~0,5 ГБ |
| БД и образы Docker | образы Docker ~10–15 ГБ; БД небольшая |

Итог: 132 ГБ хватает с большим запасом, даже с учётом локальных бэкапов (лимит на них ≤20% диска). Контроль свободного места остаётся (`infra/vm_setup.md`, раздел 7).

- Первый вход, смена пароля, установка Docker Engine + Compose v2 — не выполнены.
