# Decision Log — DEC-2026-11-24

## Решение

> CR-022 Approved: корректировка UI раздела «Потребности» по референсам владельца (пункты 3.1–3.12)

---

## Контекст

Владелец передал 24.11.2026 референсы (скрин 3 — эталон вида раздела, скрин 4 — эталон меню статусов) и список пунктов 3.1–3.12: радиусы кнопок, шрифты и цвета пилюль (ярче), иконка у «Обновить», блок фильтров с дата-диапазоном, радиусы таблицы, «Изменить ⌄» вместо кнопок статусов с иконками, шевроны у «Правила»/«N кандидатов»/«Сопоставить», ⌄→⌃, «Суб», столбец «Ставка» (шрифт, одна строка, «—»), без кебаб-меню, шапка таблицы −20%. Затронуты FR-011, FR-034, FR-035, FR-036, FR-038.

---

## Обоснование

Автоскор 4.5 (Modify) перекрыт решением владельца: Impact=High — артефакт широких derives-связей (BFS 70 узлов, реально 5 целевых); стоимость Medium, один круг UX+Dev. CR-022 открывает эпик REW-45: UX (Pre.UX-16, KON-166) → апрув владельца → Dev → QA.

---

## Рассмотренные альтернативы

### Вариант 1: Держать текущий вид раздела (без правок)

- **Плюсы:** Нулевые затраты  
- **Минусы:** Вид не соответствует референсу владельца  
- **Почему отклонён:** Отклонено владельцем 24.11.2026

### Вариант 2: Полный редизайн по референсу, включая кебаб-меню

- **Плюсы:** Максимальное сходство с референсом  
- **Минусы:** Лишняя функциональность, владелец явно исключил её (3.11)  
- **Почему отклонён:** Исключено пунктом 3.11 референса

### Вариант 3: Разбить на два CR (косметика + дата-фильтр)

- **Плюсы:** Меньше формальность каждого CR  
- **Минусы:** Изменения согласованы владельцем одним пакетом; лишний цикл 5.4/5.5  
- **Почему отклонён:** Ведём одним CR-022
