## Формулировка

> _Формулировка: «Система ДОЛЖНА [действие]...»_

Система ДОЛЖНА позволять настроить внешние LLM через ввод API Key и URL. По умолчанию используется корпоративная Qwen. Claude подключается только через API-ключ, не через личный аккаунт. Во внешнюю модель уходит только обезличенный текст (FR-023). Ключи ДОЛЖНЫ храниться зашифрованно (NFR-006). Таймаут запроса к LLM — 120 с, настраиваемый.

## Обоснование

Гибкость выбора модели без изменения кода.

## Ограничения и допущения

Кто может менять настройки — администратор приложения (допущение).
