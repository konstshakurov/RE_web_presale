## Формулировка

> _Формулировка: «Система ДОЛЖНА [действие]...»_

Пользователь ДОЛЖЕН мочь скачать любой файл сотрудника и удалить файл типа «Доп. CV» или «Материалы» из списка в столбце «Файлы». Загруженное актуальное (последнее) основное CV напрямую не удаляется, оно только заменяется новым (FR-039).

Критерии приёмки: (1) кнопка скачивания отдаёт исходный файл без изменений; (2) удалённый файл исчезает из списка и не участвует в сопоставлении и назначении; (3) для актуального основного CV действие «Удалить» недоступно.

## Обоснование

Управление файлами сотрудника в карточке без обращения к администратору. Выделено из FR-022 по результатам верификации 7.2 (атомарность). Запрет удаления актуального основного CV подтверждён пользователем 02.10.

## Ограничения и допущения

Подтверждено пользователем 02.10: актуальное загруженное основное CV не удаляется, только заменяется.
