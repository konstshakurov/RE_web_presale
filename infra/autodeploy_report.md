## Что сделано

| Файл | Назначение |
|---|---|
| `scripts/deploy.ps1` | Локальный оркестратор: проверки до выкладки (чистое дерево, HEAD запушен, ветка `main`, backend unit-тесты, сборка frontend, `check_secrets.sh` — красная проверка отменяет деплой ДО отправки) → `git archive HEAD` (список путей как в `infra/deploy.md` §1) → scp архива и `deploy.sh` → запуск деплоя на ВМ → сверка `DEPLOYED_VERSION` |
| `scripts/deploy.sh` | ВМ-скрипт (ядро): flock (параллельный запуск отклоняется), короткое замыкание при повторе того же коммита, CRLF-проверка архива, `app.prev.<время>` с ретеншеном (3 копии), миграции только при изменении `db/migrations/` (перед ними дамп через механизм KON-49), `docker compose build/up` боевого оверлея, ожидание `/health` и healthy всех 5 сервисов (300 с), авто-откат на `app.prev` при любой красной проверке (без `down -v`), журнал и `DEPLOYED_VERSION` |
| `.gitattributes` | `*.sh`, `*.py`, `*.yml`, `*.conf`, `Dockerfile*` → `eol=lf` — риск CRLF в архиве закрыт |
| `infra/deploy.md` §0b | инструкция автодеплоя, журнал, откат |

## Критерии приёмки → как проверено

| Критерий | Проверка |
|---|---|
| Пуш в main → ВМ обновлена, `DEPLOYED_VERSION` = хеш | прогон 12:10 (`3bf0401`) |
| Красная проверка — отмена/откат | отмена до scp: тесты/сборка/секреты (реальный сбой на миграциях → откат 11:43) |
| Повтор того же коммита безопасен | short-circuit в `deploy.sh` («SKIP версия … уже на стенде»); контрольный повтор — при следующем прогоне |
| Нет секретов в скриптах и выводе | `check_secrets.sh`, шаблоны, `.env` не читается и не печатается |
| Параллельный запуск | `flock -n` → REJECT, код 3 |
| Журнал и откат вручную | `deploy.log` (история 11:43 и 12:10), `infra/deploy.md` §2 |

## Операции для владельца

1. Обычный деплой: `powershell -ExecutionPolicy Bypass -File .\scripts\deploy.ps1`
   (VPN включён; ключ в ssh-agent: `ssh-add $env:USERPROFILE\.ssh\id_ed25519_vm_re` — раз за сессию).
2. Быстрый повтор без проверок (только для повторов до приёмки):
   `.\scripts\deploy.ps1 -SkipBackendTests -SkipFrontendBuild -SkipSecretsCheck`.
3. Журнал/состояние: `ssh user@vm-re.simbirsoft tail -30 /opt/re_web_presale/deploy.log`;
   `cat /opt/re_web_presale/DEPLOYED_VERSION`.
