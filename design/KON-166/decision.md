## Что реализовать (по финальному состоянию `variant_a.html`)

Компоненты: `NeedsPage.tsx`, `NeedsTable.tsx`, `StatusActions.tsx` (меню вместо кнопок-ссылок),
`ClientRules.tsx`, `NeedCandidates.tsx`, `Header.tsx` (шапка), `styles.css` (токены и стили).

### Блок фильтров (FR-034 v1.3, CR-022 3.3)
- Поиск по ключу и названию с очисткой (X) — иконка лупы слева, X справа, aria-label «Поиск по ключу и названию».
- Дата-диапазон по дате создания (столбец «Создана»): одно поле-контейнер с иконками календаря по краям, два `input[type=date]`, разделитель «—», aria-label «Создана с / Создана по».
- Быстрые кнопки «Сегодня», «7 дней», «30 дней», «Сбросить даты»; активная кнопка — синий контур + усиленная заливка.
- Невыделенные чипы групп статусов и кнопки дат: заливка `#f7f9fe`, контур — тот же токен `--border`, что у поля поиска; текст/счётчики без изменений; hover — синий контур.
- Disabled «Сбросить даты» (даты не заданы): та же заливка и контур, текст приглушён (`--muted`), hover не меняет контур.
- «Обновить» — без иконки внутри кнопки; иконка обновления — перед текстом штампа «актуально на …».
- Текст JQL — только чтение, под блоком фильтров.

### Таблица
- Столбцы по текущей реализации: Ключ, Автор, Название, Статус, Клиент, Контракт, Ставка, Кандидаты (с ⓘ-подсказкой), Создана (сортировка ▲/▼).
- Строки: шрифт 13px (было 14px), line-height 1.16.
- Шапка таблицы: прежняя высота (padding 10px, шрифт 13px) — п. 3.12 отменён.
- Контейнер: радиусы 12px по референсу + затемнение по контуру, как у блока фильтров.
- Hover строки `--row-hover`, раскрытая строка `--row-sel` с левой полосой 3px (KON-149 — без изменений).

### Столбец «Статус» (FR-011 v1.5)
- Облачко статуса: прежние пастельные цвета фона и цветного текста (карта `statusTone.ts` — без изменений), полностью круглое (`border-radius:999px`, padding 5px 10px, высота ≈25px), вес 450, шеврона нет.
- Под облачком кнопка «Изменить ⌄» — блочный flex (`display:flex; width:max-content`), от левого края столбца, на одной вертикальной линии с краем облачка (сдвиг к слову был отменён владельцем — раунд 4а отклонён).
- Кнопка открывает выпадающее меню ТОЛЬКО доступных Jira-переходов (FR-026): «Требуется кандидат» → Поиск/Найм/Кандидатов нет; «Поиск кандидата» → Найм/Кандидатов нет; «Кандидатов нет» → Поиск/Найм; «Найм» → Поиск/Кандидатов нет; «Кандидат назначен» → Поиск/Найм/Кандидатов нет. Эталон вида пунктов — скрин 4 (иконка у каждого пункта: лупа, портфель, перечёркивание).
- Для статусов без переходов (включая «Отказ по кандидату») кнопки «Изменить» нет.
- Клавиатура/a11y: `aria-expanded`, `aria-haspopup="menu"`, `role="menu"`/`menuitem`, фокус на первом пункте при открытии, выбор и закрытие (Esc, повторный клик) без мыши, видимый фокус.
- Поведение переходов не меняется: «Кандидатов нет» — обязательные поля Jira; «Поиск кандидата» — подтверждение одним кликом; «Найм» — предзаполнение полей ставки; запрос переходов — как реализовано (GET status-actions при открытии).

### Кнопки внутри таблицы
- Высота 25px, вес 450: «Сопоставить ⌄» (заливка синим, белый текст), «ROS» (контурная, не меняется), «Резюме», «Назначить», «Пересчитать», селект «LLM по умолчанию».
- Шеврон селекта: `appearance:none`, кастомный шеврон с отступом 8px от правого края (в тёмной теме — свой цвет стрелки).
- «Сопоставить ⌄», «N кандидатов ⌄», «Правила ⌄» — шеврон на одной линии с текстом, в активном состоянии ⌃ (поворот svg 180°); `aria-expanded`/`aria-controls`.

### Раскрытые блоки (inline под строкой)
- Белые карточки на голубом фоне (`--row-sel`); цветовое решение UX, принято владельцем.
- Блок кандидатов: БЕЗ строки заголовков колонок (убраны раундом 6); раскладка — как в текущей реализации: ФИО + ключ + чип статуса | «Совпадение»: % -пилюля, навыки, 📌-заметка | «Рекомендации»: обоснование + «Чего не хватает до 100%» | кнопки «Резюме»/«Назначить» справа; строка «Рассчитано: …», селект модели, «Пересчитать».
- Блок правил: заголовок во всю ширину, слева kv-таблица «Правила из полей карточки эпика (FR-015)», справа карточки «Правила из комментариев эпика» со счётчиком источников, футер «Получено из Jira …».

### Ставка (FR-034 v1.3)
- Значение «2 240 RUB» — одна строка без переноса (`white-space:nowrap`), шрифтом строки (13px), вес 700 (как было).
- «с НДС» / «от клиента» / «от произв.» — 13px (как основной шрифт таблицы), muted.
- Нет значения — «—» (muted, без «не указана»).

### Прочее
- «Субподряд» → «Суб» (чип группы и значение столбца «Контракт»).
- Шапка системы: разделы навигации и имя пользователя — вес 450; невыделенный пункт и имя — белый цвет; активный раздел — как сейчас (светлая вкладка); иконка выхода — белая; логотип — как в текущей реализации (ассеты KON-135 `logo_head.svg` + `logo_wordmark.svg`, размеры по `Header.tsx`: head 34px, wordmark 21.5/48 от head; Dev использует существующие ассеты, копировать в приложение не нужно).

## Токены и стили
- Гарнитура не меняется: `system-ui`, без @font-face (зафиксировано тестом `header.test.tsx`).
- Вес: **450** для обычного текста (замена 400) — глобально; в шапке системы навигация/имя — 450; исключений с 500 нет (600+ — заголовки, счётчики, «2 240 RUB» — без изменений).
- Размеры: строки таблицы 13px; кнопки таблицы и облачко статуса 25px; селекты блока кандидатов 25px.
- Радиусы: кнопки 8px; чипы/облачка 999px; контейнеры (фильтры, таблица, поповеры B) 12px.
- Цвета (светлая тема, палитра А2 KON-149 + решения CR-022): невыделенные чипы/кнопки дат `#f7f9fe` + контур `--border`; синий акцент чипов групп и кнопок `#1a66d9` (hover `#1554b8`), быстрые состояния `#e8f0fd`/`#d8e6fb`; облачка статусов — пары statusTone (`--chip-*-bg/fg`); раскрытые блоки — `--row-sel` + белые карточки; затемнение контура `0 1px 3px rgba(16,24,40,.08)` у блока фильтров и контейнера таблицы.
- Новые/изменяемые токены Dev вводит по этому списку: `--n-blue`, `--n-blue-hover`, `--n-tint`, `--n-tint-strong`, `--chip-bg`, `--chip-fg`, `--chip-border`, `--qbtn-bg`, `--qbtn-border`, `--contour` (светлые значения — как в прототипе; тёмные — «как сейчас»).
- Тёмная тема НЕ меняется (включая облачка статусов: фон `--panel-2` + цветной текст, чипы групп — как сейчас).

## Данные и API
- Дата-диапазон «Создана»: фильтрация на стороне API/кэша (параметры запроса createdFrom/createdTo — как реализовано), комбинируется по И с группой статусов и поиском; «Сбросить даты» очищает поля и снимает ограничение.
- Меню «Изменить ⌄»: состав — только доступные Jira-переходы (FR-026, GET status-actions при клике); справочник причин и поля переходов запрашиваются у Jira, не хранятся в приложении; поведение и поля переходов — без изменений (FR-011).
- «N кандидатов»/«Сопоставить»/кэш результата/правила объективности — без изменений (FR-036 v1.3); «ROS» — реализована, не трогается (FR-041/BF-12).
- Логотип: ассеты уже в продукте (KON-135), Dev использует существующие (`frontend/src/assets/`).
- Демо-данные прототипов вымышленные; реальных ФИО/логинов из референсов и `input/` не содержат.

## Критерии приёмки UI (для Dev и QA)
1. Состав и названия столбцов соответствуют текущей реализации: Ключ, Автор, Название, Статус, Клиент, Контракт, Ставка, Кандидаты, Создана.
2. Дата-диапазон фильтрует таблицу по дате создания («Создана»); «Сегодня»/«7 дней»/«30 дней» заполняют диапазон; «Сбросить даты» очищает поля и снимает ограничение; комбинируется по И с группой статусов и поиском.
3. Невыделенные чипы групп и кнопки дат — заливка #f7f9fe и контур `--border` (тот же, что у поля поиска); выделенные — по варианту UX (синий); disabled «Сбросить даты» — невыделенный с приглушённым текстом.
4. Поиск очищается крестиком (X); поле поиска с aria-label.
5. Строки таблицы — 13px, line-height 1.16; шапка таблицы — прежней высоты; контейнер таблицы — радиусы 12px и затемнение по контуру, как у блока фильтров.
6. Облачко статуса: пастельные цвета прежние (не белый текст), полностью круглое (999px), вес 450, без шеврона; для статусов без переходов кнопки «Изменить» нет.
7. «Изменить ⌄» — от левого края столбца «Статус», на одной линии с краем облачка; меню показывает только доступные переходы (FR-026), у каждого пункта иконка; aria-expanded корректен, фокус видим, открытие/закрытие/выбор с клавиатуры.
8. Кнопки таблицы («Сопоставить», «ROS», «Резюме», «Назначить», «Пересчитать», селект «LLM») — 25px, вес 450; шеврон селекта с отступом 8px от края.
9. «Сопоставить ⌄», «N кандидатов ⌄», «Правила ⌄» — шеврон на одной линии с текстом; в активном состоянии — ⌃. Кебаб-меню отсутствует.
10. Раскрытые блоки «Правила» и «Кандидаты/Сопоставить» — белые карточки на голубом фоне, БЕЗ заголовков колонок в блоке кандидатов; внутренняя раскладка (заметки, навыки) — как в текущей реализации.
11. Ставка: «2 240 RUB» в одну строку без переноса, шрифтом строки (13px); «с НДС»/«от клиента»/«от произв.» — 13px; при отсутствии — «—».
12. «Субподряд» отображается «Суб» (чип группы и столбец «Контракт»).
13. «Обновить» — без иконки внутри кнопки; иконка обновления перед штампом «актуально на …»; штамп времени и счётчик потребностей сохраняются.
14. Шапка: навигация и имя пользователя — вес 450, невыделенные — белые; иконка выхода белая; логотип — head + wordmark из KON-135 (head 34px, wordmark 21.5/48).
15. Вес 450 применён везде, где был 400; гарнитура system-ui без @font-face.
16. Обе темы (светлая А2 / тёмная — без изменений) и ширины 1280 и 1024 — соответствуют прототипу `variant_a.html` и скриншотам `variant_a_needs_*.png`.

## Вне объёма
- Пагинация: «Назад/Вперёд» + «На странице» — как сейчас (открытый вопрос о нумерации из референса остался без ответа — не делаем; решение отдельным CR при необходимости).
- Кебаб-меню из референса — не делаем (п. 3.11).
- ROS — не трогаем (реализована, FR-041/BF-12).
- Тёмная тема — не меняем.
- Стрелка сортировки ▼ у «Создана» — оставлена как сейчас (сортировка по FR-034).
- Состав групп чипов — конфигурируемый в «Настройках»; чип «Суб» в прототипе демонстрационный.
- Hex референса — значения подобраны прототипом (PNG-исходника нет); при появлении исходника макета — сверка отдельным пунктом.
- Состояния загрузки/ошибки/пусто — без изменений (вне скоупа CR-022).
