# KON-92 Закреплённая шапка приложения — решение по UI

Статус: approved | дата: 15.10.2026 | утвердил: Константин
Выбран вариант: «после» (sticky-шапка); поправки владельца: баннер Jira остаётся в потоке страницы, тень и граница у шапки не нужны.

**Изменено 27.10.2026: высота шапки 56 px заменена решением KON-135 (`design/KON-135/decision.md`): теперь 64 px; `scroll-padding-top` — 64 px.** Остальное (sticky, z-index, баннер Jira, модалки, экран входа) без изменений. Прежние значения 56 px ниже зачёркнуты и сохранены для истории.

## Что реализовать
- Шапка `.topbar` закреплена в верхней части окна на всех экранах после входа: `position: sticky; top: 0; z-index: 5`. Высота ~~56px~~ **64px (заменено решением KON-135)**, вид и «Выйти» по KON-135 (меню пользователя нет).
- `html { scroll-padding-top: ~~56px~~ 64px (заменено решением KON-135) }` — элементы, на которые уходит фокус или прокрутка, не скрываются под шапкой.
- `JiraBanner` остаётся в потоке страницы под шапкой и прокручивается вместе с содержимым (утверждено владельцем 15.10.2026).
- Модальные окна (`.modal-backdrop`, `z-index: 10`) остаются поверх шапки.
- Экран входа: шапка без меню, не меняется (страница не прокручивается).

## Токены и стили
Новых токенов нет. Используется `--nav`; высота ~~56px~~ 64px (заменено решением KON-135).

## Данные и API
Не требуются.

## Критерии приёмки UI
1. На «Потребностях», «Сотрудниках», «Резюме», «Настройках» при прокрутке содержимого на любую величину `.topbar.getBoundingClientRect().top === 0`.
2. Высота шапки ~~56px~~ **64px (заменено решением KON-135)**; логотип, пункты меню, имя пользователя, чип и «Выйти» — по `design/KON-135/decision.md` (критерии шапки там).
3. Первая строка таблицы при прокрутке уходит под шапку, не перекрывая её; в начале страницы верхний отступ содержимого прежний (24px).
4. Tab на элемент, расположенный ниже окна, прокручивает страницу так, что элемент не оказывается под шапкой.
5. Открытое модальное окно (Профиль, CV, «Как подбираются кандидаты», «Назначить» позже) затемняет шапку; шапка не перехватывает клики и не перекрывает окно.
6. Баннер Jira: при прокрутке уходит за шапку, шапка его не перекрывает в начале страницы.
7. Обе темы; окна 1280 и 1024; при высоте окна 400px страница прокручивается, шапка на месте.
8. Экран входа без изменений.

## Вне объёма
Закрепление заголовков таблиц, закрепление баннера Jira, меню пользователя. (Высота и вид шапки изменены решением KON-135.)
