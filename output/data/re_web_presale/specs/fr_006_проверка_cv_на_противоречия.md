## Формулировка

> _Формулировка: «Система ДОЛЖНА [действие]...»_

Система ДОЛЖНА по запросу проверять CV с помощью LLM на внутренние противоречия (например, пересечение периодов проектов, несоответствие лет опыта и стека, расхождение между разделами) и показывать отчёт с найденными пунктами и рекомендациями. Метрик качества проверки не задаётся.

## Обоснование

Снижает риск отправки клиенту некорректного CV. Перечень типов противоречий — допущение аналитика.

## Ограничения и допущения

См. FR-023 при использовании внешней LLM.
