# Decision Log — DEC-05102026

**Проект:** re_web_presale  
**Дата:** 05.10.2026  
**Тип:** Scope  
**Принял решение:** Константин Шакуров (спонсор, accountable)

---

## Решение

> Горизонт MVP сокращён до 1 месяца (цель — быстрее за счёт агентов); интеграция с Jira — методом проб, сроки ставит ассистент; Application Link — запасной вариант.

---

## Контекст

После закрытия глав 3–7 и baseline v1.0 уточняется план разработки. Ответ Support по Application Link (AS-001/RK-001) не получен; разработка идёт агентами, интеграцию с Jira делает OpenCode с другой LLM, у которой есть доступ к корпоративной Jira без прокси.

---

## Обоснование

Разработка только ИИ-агентами, MVP небольшой; основной риск (Jira) снимается ранней пробой.

---

## Рассмотренные альтернативы

### Вариант 1: Горизонт 3 месяца (6.4)

- **Плюсы:** Запас  
- **Минусы:** Избыточен при агентской разработке  
- **Почему отклонён:** Заказчик: кодим агентами, справимся быстрее

### Вариант 2: Ждать ответа Support по Application Link

- **Плюсы:** Предсказуемая аутентификация  
- **Минусы:** Блокирует разработку  
- **Почему отклонён:** Решено идти методом проб; Application Link — запасной путь
