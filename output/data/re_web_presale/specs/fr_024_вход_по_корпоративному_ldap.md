## Формулировка

> _Формулировка: «Система ДОЛЖНА [действие]...»_

Система ДОЛЖНА выполнять вход пользователя по корпоративному LDAP. Пароль НЕ ДОЛЖЕН сохраняться. Сессия создаётся только при успешном LDAP-входе и наличии пользователя в списке администратора (FR-021).

При истёкшей сессии (401 на защищённый маршрут) система ДОЛЖНА перенаправить пользователя на страницу входа с сообщением «Сессия истекла. Войдите снова - вы вернётесь на прежнюю страницу.»; сообщение НЕ ДОЛЖНО показываться при первом входе и при ошибке пароля. После успешного входа система ДОЛЖНА открыть прежнюю страницу.

## Обоснование

Использование единой корпоративной учётной записи.

## Ограничения и допущения

Параметры LDAP получены от Support (09.10.2026): сервер `ldap://freeipa01.simbirsoft:389/`, base DN `cn=users,cn=accounts,dc=simbirsoft,dc=dev`, bind `uid={login},cn=users,cn=accounts,dc=simbirsoft,dc=dev` (прямой bind под учётными данными пользователя, служебная учётка не нужна). TLS не используется (`ldap://`).
