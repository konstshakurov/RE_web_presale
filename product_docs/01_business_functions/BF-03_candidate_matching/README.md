### Промпт рекомендаций (быстрый доступ)

Точный промпт — код: [`backend/app/matching/prompts.py`](../../../backend/app/matching/prompts.py). Актуален после CR-019 (деплой 09.11.2026).

| Что | Где в файле | Суть |
|---|---|---|
| Системная часть | константы `MATCH_SYSTEM` + `CONSISTENCY_INSTRUCTION` + `GAPS_INSTRUCTION` (склеены) | правила CR-019: оценка только по требованиям потребности, без собственных порогов/грейдов; формулировки «в CV не указан»; согласованность percent↔gaps; без модальностей «может считаться/не соответствовать». Формат ответа — строгий JSON: `{id, percent, rationale, gaps}` |
| Пользовательская часть | `build_match_prompt` (+ `candidate_block`) | блок ПОТРЕБНОСТЬ (название ≤500, описание ≤3000, требования ≤3000) и блоки КАНДИДАТЫ: навыки, заметка (≤1000), «Подробнее об опыте» (≤1500), текст Основного CV (≤6 000) |
| Пост-обработка | `objectify_output` внутри `parse_match` | гарантирует правила 2 и 4 кодом: «нет опыта» → «Не указан опыт», удаление фраз с модальностями, снятие стартового «Кандидат» и отдельных «В CV» (решение владельца 09.11); работает для сопоставления, semantic-поиска и скрининга |

Semantic-поиск («Резюме») использует то же ядро: `backend/app/matching/semantic.py`, константа `SEARCH_SYSTEM`.

Документы: правила в спеках — FR-005 v1.1 / FR-036 v1.2 (таблица «Требования» выше); решение — [`5_4_cr_decision_CR-019_20261109_093543.md`](../../../output/reports/re_web_presale/5_4_cr_decision_CR-019_20261109_093543.md).
