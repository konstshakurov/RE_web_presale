## Формулировка

> _Формулировка: «Система ДОЛЖНА [действие]...»_

В окне «Назначить» кнопка «CV по шаблону» ДОЛЖНА с помощью LLM формировать CV по шаблону клиента: на вход LLM получает файл шаблона клиента и Основное CV сотрудника. Перед запуском пользователь ДОЛЖЕН подтвердить, какой файл шаблона (вложение потребности/эпика или загружаемый) и какое Основное CV используются. Модель по умолчанию — внутренняя; пользователь МОЖЕТ выбрать другую, в том числе внешнюю. Перед созданием система ДОЛЖНА проверить, не создавалось ли CV для пары сотрудник/клиент; при повторе показывает ранее созданное. Результат сохраняется как файл типа «CV по шаблону клиента», выбирается в окне «Назначить» вместо Основного CV и может быть скачан для правки.

## Обоснование

Решение 01.10 и часть 2 ФТ: функция вызывается из окна назначения.
