## Формулировка

> _Формулировка: «Система ДОЛЖНА [действие]...»_

Файл «Основное CV» ДОЛЖЕН быть главным источником компетенций сотрудника для сопоставления с потребностями (FR-036). При загрузке основного CV система ДОЛЖНА извлечь из него текст, сохранить его и показать статус извлечения (успешно / ошибка / нет файла); при ошибке — сообщение пользователю. Из текста система ДОЛЖНА выделить технологии и навыки (с помощью LLM, результат кэшируется и пересчитывается только при замене файла) — они используются для фильтра по технологии (FR-032) и сопоставления. Прежняя логика «флажок корпоративного CV / имя файла SimbirSoft» отменяется: основным становится файл, загруженный с типом «Основное CV».

## Обоснование

Часть 2 ФТ. Извлечение один раз при загрузке экономит вызовы LLM и ускоряет сопоставление (предложение аналитика).

## Ограничения и допущения

Версия 2: заменяет «Пометка корпоративного CV флажком» (ISS-007). Для выделения технологий у внешней LLM — FR-023.
