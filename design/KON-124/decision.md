## Изменения в интерфейсе (Точки изменения для Dev)

1. **NeedsTable.tsx, кнопка правил в строке потребности** (`td` «Клиент»):
   видимый текст `«Правила клиента»` → `«Правила»` (состояние раскрыто: `«Скрыть правила»` —
   без изменений); полная подпись «Правила клиента» сохраняется в `title` кнопки
   (в свернутом состоянии). Доступ: имя кнопки для скринридера — «Правила»
   (тесты `needs.test.tsx` обновлены в рамках задачи).
2. **NeedsTable.tsx, колонка «Ставка», подпись источника** (`rate.proposer`):
   отображение `«от производства»` → `«от произв.»`; значение из API не меняется,
   полный текст — в `title`; CSS: `white-space: nowrap`, при дефиците ширины
   `text-overflow: ellipsis` (класс `rate__proposer`, максимум 96 px) — перенос исключён.
3. **NeedsTable.tsx, колонка «Кандидаты»**: видимый текст `«Скрыть кандидатов»` → `«Скрыть»`;
   доступ: `aria-label="Скрыть кандидатов"` сохраняется. Ссылка «N кандидатов»
   (`candidatesLabel`) — без изменений.
4. **EmployeesPage, `.acts` в карточке сотрудника** (кнопки «Профиль / Резюме / Файлы»):
   `flex-wrap: wrap` → `nowrap`, gap 14 px → 6 px, паддинг `.act` 6/8 → 6/4; подписи
   не сокращаются (полный текст трёх кнопок + иконки ≈260 px < 280 px минимальной
   ширины карточки) — перенос невозможен, «Файлы» больше не уходит на вторую строку.
