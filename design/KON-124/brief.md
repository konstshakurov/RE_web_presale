# Brief: KON-124 — Pre.UX-N, правки текстов и переносов (Потребности, Сотрудники)

- Источник: Linear KON-124, правки заданы владельцем 22.10.2026 (после проверки стенда на ВМ).
- По правилу владельца достаточно **одного варианта + «как сейчас»**; требований не меняет.
- Вне MVP (метка «Версия 2») — для второго этапа.

## «Как сейчас» (скриншоты вне git, `input/screenshots/`)

- `stage2_ux_needs_texts.png` — «Потребности»: ссылка «Правила клиента», текст «от производства»
  переносится на новую строку, ссылка «Скрыть кандидатов».
- `stage2_ux_employees_buttons_one_line.png` — «Сотрудники»: кнопки «Профиль / Резюме / Файлы»
  уходят на две строки (карточка «Аблязова И.С.»).

## Вариант A — правки

1. Ссылка «Правила клиента» → **«Правила»**, текст правила остаётся в подсказке
   `title="Правила клиента"` — ясность сохранена, строка короче.
2. Колонка «Ставка»: **«от производства» → «от произв.»**, `white-space: nowrap`;
   при дефиците ширины — `text-overflow: ellipsis` и полный текст в `title`
   (перенос исключён, сокращение только точечное, решение UX ниже).
3. Ссылка «Скрыть кандидатов» → **«Скрыть»**; ссылка «N кандидатов» остаётся без изменений.
4. Кнопки «Профиль / Резюме / Файлы» в карточке сотрудника: `display:flex; flex-wrap:nowrap`,
   без переносов. При дефиците ширины сжимаются только отступы (gap 10 → 4 px через `clamp`);
   подписи не обрезаются: полный текст трёх кнопок с иконками занимает около 260 px,
   что меньше минимальной ширины карточки (~280 px при minmax(300px,1fr)) — поэтому
   одна строка гарантирована даже при узком окне.

## Критерии приёмки (из задачи, для QA)

- Тексты и ссылки как выше, в обеих темах.
- Ширины 1280 и 1024, масштабы 80–125%: «от произв.» и три кнопки не переносятся,
  горизонтальной прокрутки карточки нет.
- Ничего не сломано: «Правила», «Скрыть», «N кандидатов», «Профиль/Резюме/Файлы»
  работают как раньше.
