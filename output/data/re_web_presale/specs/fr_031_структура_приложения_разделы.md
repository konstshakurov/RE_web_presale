## Формулировка

> _Формулировка: «Система ДОЛЖНА [действие]...»_

Приложение ДОЛЖНО содержать разделы верхнего меню: «Потребности» (стартовая страница), «Сотрудники», «Резюме», «Настройки» (только для администратора). «Сотрудники» — список карточек Jira со статусом, отпусками, историей отправок (FR-016) и переходом в «Резюме»; «Резюме» — рабочий раздел файлов, заметок и поиска (FR-022, FR-032, FR-033). «Настройки» — список доступа (FR-021), LLM-провайдеры (FR-030), JQL потребностей, группы статусов (FR-035), ставка НДС (BR-009), лимит размера файла. Диалог с LLM (FR-007) доступен из раздела «Потребности» и окна просмотра CV. Не-админ раздел «Настройки» не видит.

## Обоснование

Часть 2 ФТ: согласование структуры. Предложение: «Сотрудники» оставить лёгким справочником (статус/отпуска/история), чтобы не дублировать «Резюме».

## Ограничения и допущения

Предложение для упрощения MVP: «Сотрудники» можно отложить на этап 2, т.к. статус и фильтр уже есть в «Резюме».
