## Формулировка

> _Формулировка: «Система ДОЛЖНА [действие]...»_

Система ДОЛЖНА предоставлять диалоговое окно с LLM, в котором пользователь задаёт запросы в контексте выбранной потребности, CV или рекомендации и получает ответ. При использовании внешней LLM в неё ДОЛЖЕН уходить только обезличенный текст.

## Обоснование

Гибкий доступ к LLM для задач, не покрытых готовыми функциями.
