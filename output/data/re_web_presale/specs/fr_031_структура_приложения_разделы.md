## Формулировка

> _Формулировка: «Система ДОЛЖНА [действие]...»_

Приложение ДОЛЖНО содержать разделы верхнего меню: «Потребности» (стартовая страница), «Сотрудники», «Резюме», «Настройки» (только для администратора). «Сотрудники» — список карточек Jira со статусом, отпусками, историей отправок (FR-016) и переходом в «Резюме»; «Резюме» — рабочий раздел файлов, заметок и поиска (FR-022, FR-032, FR-033). «Настройки» — список доступа (FR-021), LLM-провайдеры (FR-030), JQL потребностей, группы статусов (FR-035), ставка НДС (BR-009), лимит размера файла. Диалог с LLM (FR-007) доступен из раздела «Потребности» и окна просмотра CV. Не-админ раздел «Настройки» не видит.

Шапка приложения с верхним меню ДОЛЖНА быть всегда видна при прокрутке страницы (закреплена, высота 64 px); прокручивается только содержимое под ней. По решению design/KON-135 (approved): логотип — два ассета (голова 34 px и надпись «regoose»); чип «Админ» показывается только при фактической роли администратора; отдельное меню пользователя отсутствует — в шапке имя, чип и иконка выхода; элементы шапки ДОЛЖНЫ стоять на одной горизонтальной оси; активная вкладка — цвет --bg со скруглёнными верхними углами; фирменный шрифт в интерфейс не подключается. Маршруты, авторизация и выход не меняются. Баннер состояния Jira остаётся в потоке страницы, модальные окна открываются поверх шапки, экран входа (шапка без меню) не меняется.

## Acceptance Criteria

1. Высота закреплённой шапки — 64 px на всех страницах; контент прокручивается под ней.
2. Логотип собран из двух ассетов (голова 34 px + надпись regoose); на странице входа — логотип без меню.
3. Чип «Админ» виден только пользователю с фактической ролью admin.
4. Меню пользователя отсутствует: показываются имя, чип (если админ) и иконка выхода.
5. Элементы шапки выровнены по одной горизонтальной оси; активная вкладка — цвет --bg со скруглёнными верхними углами.
6. Разделы и их состав соответствуют формулировке; не-админ не видит «Настройки».
7. Модальные окна открываются поверх шапки; баннер Jira прокручивается вместе со страницей.
