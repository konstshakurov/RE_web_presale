# Brief: KON-80 — Pre.UX-3, «CV по шаблону клиента» (FR-017, FR-012, UC-004, FR-023, BR-007)

- Вход: KON-45 (Dev-14), спеки `fr_017*`, `fr_012*`, `uc_004*`, `fr_023*`, `br_007*`,
  решение Pre.UX-2 (`design/KON-79/decision.md`), `design/tokens.md`.
- Диалог открывается кнопкой secondary «CV по шаблону клиента…» из окна «Назначить».
- Этап 2; владелец допустил сдвиг за 05.11 (чат 02.11.2026).

## Сценарий (UC-004, FR-017)

1. **Подтверждение файлов.** До генерации подтверждаются два входа: файл шаблона
   клиента (из «Файлы» потребности) и Основной CV сотрудника.
   Без подтверждения генерация не стартует (критерий Dev-14).
2. **Выбор модели LLM** — как в семантическом поиске, предзаполняется последней.
3. **Предупреждение о повторе** (BR-007, FR-023): если для пары «сотрудник + клиент»
   уже есть сохранённый CV по шаблону — предупреждение с датой прежнего и выбором
   «Продолжить / Отмена». Повтор не блокируется.
4. **Прогресс генерации** (шаги: шаблон → CV → генерация); во время отправки окно не закрывается.
5. **Ошибка LLM** — текст ошибки шлюза, выбор сохранён, кнопка «Повторить».
6. **Результат** — предпросмотр CV, «Рекомендации по адаптации» (FR-012), черновик письма.
   Результат сохраняется с типом «CV по шаблону клиента» и указанием клиента.
   Письмо публикуется комментарием в Jira только после явного апрува
   (кнопка публикации неактивна до апрува).

## Обязательные состояния

подтверждение · прогресс · ошибка LLM · повтор по паре · явный апрув перед публикацией ·
пусто · ошибка · загрузка.

## Варианты

- **A — «Мастер из 2 шагов»**: шаг 1 — подтверждение файлов и модель;
  шаг генерации с прогрессом; затем «Результат» в том же окне.
  Плюс: чёткий порядок, форма короткая; минус: лишний клик «Далее».
- **B — «Одно окно»**: подтверждения, модель и кнопка «Сгенерировать» в одной форме;
  результат появляется ниже. Плюс: нет шагов; минус: длинное окно со скроллом,
  состояние ошибки проще пропустить.

Критерии сравнения: старт без подтверждения невозможен; виден ли повтор по паре;
читаемость результата (CV + рекомендации + письмо); согласованность с окном «Назначить»
(KON-79, модал `--wide`); доступность (Tab-порядок, Esc во время генерации недоступно).
