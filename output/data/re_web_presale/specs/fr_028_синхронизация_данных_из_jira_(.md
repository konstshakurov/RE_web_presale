## Формулировка

> _Формулировка: «Система ДОЛЖНА [действие]...»_

Система ДОЛЖНА получать данные Jira опросом с локальным кэшем, без вебхуков. Потребности: инкрементальный JQL по updated каждые 5 минут, запрос только нужных полей, первичная загрузка за 6 месяцев. Сотрудники: раз в час и по кнопке. Эпики и правила клиента: при открытии, кэш 1 час (дети эпика — через Agile API). Перед записью в Jira система ДОЛЖНА перечитать потребность. Пользователю ДОЛЖНЫ быть доступны кнопка «Обновить» и штамп «актуально на». Фоновый опрос ДОЛЖЕН идти токеном любого активного пользователя (только чтение); если токенов нет, опрос приостанавливается.
