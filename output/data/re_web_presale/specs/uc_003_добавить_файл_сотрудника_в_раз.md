## Общая информация

| Атрибут | Значение |
|---------|----------|
| Актор (primary) | РН / РО / Presale-менеджер |
| Акторы (secondary) | LLM |
| Предусловие | Карточки сотрудников загружены из Jira; пользователь открыл раздел «Резюме». |
| Постусловие | Файл сохранён у сотрудника с выбранным типом; для Основного CV извлечены текст и технологии. |
| Триггер | Пользователь нажимает «Добавить» в столбце «Файлы» у сотрудника. |

## Основной сценарий (Happy Path)

1. Система открывает окно загрузки одного файла.
2. Пользователь выбирает файл и тип: «Основное CV», «Доп. CV» или «Материалы».
3. Система проверяет формат и размер.
4. Если выбрано «Основное CV» и оно уже есть — система предупреждает о замене; пользователь подтверждает.
5. Система сохраняет файл; прежнее основное CV уходит в архив.
6. Для основного CV система извлекает текст и выделяет технологии и навыки; показывает статус извлечения.

## Альтернативные сценарии

2а. Пользователь вводит или правит заметку о сотруднике (FR-033).
6а. Пользователь открывает CV в окне просмотра (FR-037).

## Сценарии исключений

3а. Формат или размер недопустимы — файл отклонён с сообщением.
6б. Не удалось извлечь текст — статус «ошибка»; файл сохранён, в сопоставлении не участвует.

## Бизнес-правила и ограничения

BR-007, FR-022, FR-027.
