# Тест-кейсы входа и доступа (Pre.QA-4, KON-56)

Область: FR-024, FR-021, UC-006, FR-031, FR-038, FR-029, NFR-006. Код продукта: `backend/app/auth/`
(KON-51, KON-53), прямой bind по `LDAP_BIND_TEMPLATE` (коммит 6265243). Пароли в файле не приводятся:
в тестах это `FAKE_*` либо значения из локального `.env` (`QA_LDAP_PW_*`).

Уровни: **A** - автотест pytest с подменой LDAP и БД (`backend/tests/qa/test_auth_flow_qa.py`);
**M** - мок-тест адаптера LDAP (`test_ldap_direct_bind_qa.py`); **I** - интеграция с одноразовым OpenLDAP
(`test_ldap_container_qa.py`, пропускается без `QA_LDAP_PW_*`); **S** - скрипт `qa/nfr006_check.py`;
**U** - тест Dev (`backend/tests/unit`, `frontend/src/test`), QA не дублирует; **R** - ручной / e2e (Playwright не заведён).
