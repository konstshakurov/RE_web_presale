## Формулировка

> _Формулировка: «Система ДОЛЖНА [действие]...»_

Система ДОЛЖНА позволять перевести потребность в статус «Кандидатов нет» и «Найм». При переходе «Кандидатов нет» ДОЛЖНЫ запрашиваться обязательные поля Jira: «Причина отсутствия кандидата» (значения справочника Jira: Нет специалистов данного уровня, но есть слабее; …конкретного набора стека; …нужной отраслевой экспертизой; …нужным специфичным стеком (стек в комментарии); Низкая ставка; Увольнение/декрет кандидата; Требуется очное присутствие; Есть прямой запрос) и «Комментарий» (видимость «для всех»). Значения справочника и обязательные поля ДОЛЖНЫ запрашиваться у Jira, а не храниться в приложении (см. FR-026).

## Обоснование

Закрытие потребностей без захода в Jira. Id поля причины неизвестен (ISS-010, ждём ответа админа Jira).

## Ограничения и допущения

Запись в Jira — этап 2. Открыто: ISS-010 (id поля, поля переходов Кандидат назначен / Найм).
