## Формулировка

> _Формулировка: «Система ДОЛЖНА [действие]...»_

Система ДОЛЖНА отображать список сотрудников (карточки Jira типа Epic) с фильтром по статусу из 10 статусов Jira: Выход новичка, Программа обучения, Внутренний проект, Свободен, Коммерческий проект, Ожидает подключения, Скоро освобождается, Недоступен для подключения, Уволен, Декрет. Для каждой карточки ДОЛЖНЫ показываться описание, отпуска и переход к CV. Для назначения на потребность ДОЛЖНЫ быть доступны сотрудники в статусах: Выход новичка, Программа обучения, Внутренний проект, Свободен, Ожидает подключения, Скоро освобождается. Сотрудники в статусах Коммерческий проект, Недоступен для подключения, Уволен, Декрет НЕ ДОЛЖНЫ назначаться.

## Обоснование

РО видит доступных людей без захода в Jira; запрет назначения исключает заведомо недоступных (ISS-003).

## Ограничения и допущения

Статусы сотрудника — workflow типа Epic (БП-8), отдельный от workflow потребности. Список сотрудников обновляется раз в час и по кнопке (FR-028).
