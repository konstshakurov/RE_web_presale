# KON-165 «Предупреждение о дубле потребности» — решение по UI

## Что реализовать

**Индикатор дублей** — новой строкой под названием потребности (интервал ~7px):
- облачко статичное: **без рамки**, без hover-эффектов и анимаций;
- высота 22px — как у пилюли «%» и кнопки «Похожая»; шрифт 12px/600;
- фон `#f8e3a8` (тёмная) / `#fdefc4` (светлая), текст `#7a4f00` / `#7c4e00`, иконка-треугольник `#e8a013` / `#dd900e`;
- текст: «N дубля/дублей» со склонением — 1 дубль / 2–4 дубля / 5–20 дублей (кроме 11–14);
- шеврон на одной линии с текстом; при раскрытии ⌄ → ⌃ (`aria-expanded`).

**Блок-раскрытие** (не новые строки таблицы): colspan-подложка под строкой (`--panel-2`,
пунктирная верхняя граница), сдвинут вправо на ширину колонки «Ключ» (84px) — ключ
начинается на линии колонки «Название». Каждая запись:
1. ключ-ссылка (у левого края блока, в первой строке по высоте);
2. название — сразу за ключом (зазор 12px), одной строкой: `ellipsis`, полное — в `title`;
3. тип: «Суб» / «Прямой»;
4. ставка — только цифра (nowrap, tabular-nums) или «—»;
5. пилюля «%» совпадения — жёлтая (`#fbeabc`/`#7a4f00`; тёмная: `rgba(245,176,65,.18)`/`--warn`);
6. кнопка классификации «Похожая ⌄».

**Кнопка классификации** (CR-023, FR-014 v1.1):
- голубое облачко `#e9f1fb`, текст `#2565b8` (тёмная) / `#1f5fa9` (светлая), **фиксированная
  ширина 120px** — не меняется при смене «Похожая» ↔ «Дубль»; текст прижат влево;
- шеврон в едином месте — правый край кнопки (`margin-left:auto`), на одной линии с текстом;
- меню: «Похожая» / «Дубль», выбранный пункт с ✓; выбор **сохраняется на сервере** и не
  сбрасывается при пересинхронизации.

**Прочее:** «дублей нет» — индикатор не показывается; ячейки таблицы — `vertical-align: top`
(ключ всегда в первой строке ячейки).

## Токены и стили
Существующие токены (`--panel-2`, `--border`, `--accent`, `--muted`, `--warn`); новых токенов
нет — цвета облачков литералами (как `.pct--*`). Переиспользуются: паттерн раскрытия строки
(`ClientRules`), пилюля процента (`.pct--*`), типографика таблицы.

## Данные и API
- Дубли считаются при синхронизации (FR-028); допущение: `GET /sync/needs` отдаёт
  `duplicates` (ключ, %, название, тип, ставка) — окончательное решение за Dev на постановке.
- Классификация «Похожая/Дубль» — отдельный вызов записи на пару потребностей (CR-023);
  сохраняется персистентно, при пересинхронизации/пересчёте не сбрасывается.
- Скрытие данных об ошибке расчёта: индикатор просто не показывается (счётчик `0`/ошибка).

## Критерии приёмки UI
1. Индикатор показывается только при наличии дублей; стоит отдельной строкой под названием с интервалом; облачко без рамки, высота 22px, статичное.
2. Клик по индикатору раскрывает/скрывает блок; шеврон меняется ⌄/⌃ и стоит на одной линии с текстом; `aria-expanded` корректен.
3. Ключ дубля начинается на линии колонки «Название»; название — сразу за ним, одной строкой, при переполнении — `ellipsis` (полное в `title`).
4. В строке дубля: «Суб»/«Прямой», ставка только цифрой или «—», пилюля «%», кнопка «Похожая ⌄».
5. Кнопка «Похожая/Дубль» сохраняет ширину при смене текста; текст слева; шеврон всегда в одном месте справа.
6. Меню классификации открывается по клику, выбранный пункт отмечен ✓; выбор сохраняется и переживает пересинхронизацию.
7. «Дублей нет» — ячейка названия без индикатора.
8. Обе темы, 1280/1024; фокус видимый; таблица не ломается при длинных названиях и 5+ дублях.
