## 3.4 Управление информацией

- **Tools:** Репозиторий GitHub (output/ — артефакты БА и СА по правилам платформы), Linear (задачи Pre.<Роль>-N)
- **Traceability:** High — Полная трассировка: Бизнес-цели → Требования → Тест-кейсы → Код
- **Access:** Редактирует Константин (аналитик). Агенты Arch, Dev, QA читают. Руководители отделов (Евгения, Дмитрий) — только чтение в GitHub; вносить изменения пока не будут.

> **BA notes:** Весь проект и артефакты хранятся в GitHub. Результаты аналитики БА и СА сохраняются в output/ по правилам платформы; задачи ведутся в Linear.
