## Формулировка

> _Формулировка: «Система ДОЛЖНА [действие]...»_

Система ДОЛЖНА показывать правила и условия клиента при работе с потребностью, показывая только заполненные поля. Источники — эпик клиента: Рекомендации (12000), Условия для производства (21801), Критерии приемки (20909), Штрафы (20910), Привлечение третьих лиц (20907), Разрешение на PR (20913), Постановка задач (20903), РИД (20904), Обязанности Заказчика (20905), Автоприемка (20906), Формат работы (14024), Тип договора (14023), NDA (14205), Описание и комментарии эпика (до 11 в SA-2219); потребность: Рисовать опыт нельзя (20302), Работа вне РФ (20914), Нужно предоставить CV (11506), Требования к кандидату (10811). Система ТОЛЬКО информирует; отправка не блокируется. Единственное исключение — правило «Нужно предоставить CV» (11506): при назначении, если Jira отклонила переход валидатором «Вложение», система временно выставляет 11506 = «Нет» и гарантированно возвращает «Да» (FR-008, CR-006).

## Обоснование

РО не пропускает условия клиента (ISS-009 принят).

## Ограничения и допущения

Эпики и правила читаются при открытии, кэш 1 ч; дети эпика — через Agile API (FR-028).
