# DEV_new_skills/ — разработка новых скиллов

Черновики и входные материалы для новых скиллов платформы, пока они не
готовы к переносу в `skills/` как самостоятельный скилл (со своим `SKILL.md`
и, при необходимости, MCP-сервером).

Когда скилл готов — перенеси его папку на уровень выше, в `skills/`, и
зарегистрируй в `CLAUDE.md` (таблица «Дополнительные скиллы» или таблица глав
BABOK, в зависимости от типа скилла).
