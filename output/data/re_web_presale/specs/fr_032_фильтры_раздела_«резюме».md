## Формулировка

> _Формулировка: «Система ДОЛЖНА [действие]...»_

Раздел «Резюме» ДОЛЖЕН содержать таблицу сотрудников со столбцами: Сотрудник (ФИО, ключ Jira, статус), Файлы (FR-022), Содержание/статус извлечения (FR-027), Описание (технологии из Основного CV), Заметка (FR-033). Фильтры: (1) «Поиск» — по ФИО, ключу, имени файла и тексту внутри CV; (2) «Статус сотрудника» (из Jira, 10 статусов); (3) «Технология» — выбор нескольких (подсказки из выделенных технологий); (4) «Поиск по смыслу (LLM)» — запрос на естественном языке; система возвращает подходящих сотрудников. Кнопки «Применить» и «Сбросить». Текстовый поиск и фильтры ДОЛЖНЫ работать без LLM. Для поиска по смыслу в этапе 1 допускается ранжирование по выделенным технологиям и тексту, LLM подключается для итогового ранжирования (предложение).

## Обоснование

Часть 2 ФТ; по референсу «Резюме сотрудников».

## Ограничения и допущения

Запрос во внешнюю LLM — только обезличенный (FR-023).

## Связанные требования

`FR-022`, `FR-027`, `FR-033`, `FR-023`
