## Что реализовать

### 1. Окно «Назначить» (`AssignDialog.tsx`)
- Убрать поле «Ставка, руб. с НДС», подсказку «В потребности: …», состояние ошибки ставки, строку «Ставка» в подтверждении, `rate_rub` из запроса.
- Форма: контекстная строка, подсказка `.note`, «Резюме», «Комментарий», «Файлы», «CV по шаблону клиента…» (secondary, KON-80). Основное действие «Назначить…» — как раньше.
- Подсказка (всегда, под контекстной строкой): «Ставка здесь не вводится: её указывают при переводе потребности в «Найм» (ссылка «Найм» в столбце «Статус»).» Если «Кто предлагает ставку» = «от производства», добавить: «В этой потребности ставку предлагает производство — при найме она будет обязательной.»
- Подтверждение: сводка без «Ставка»; два блока: «Статус изменится автоматически…» (как было) и «Ставка не передаётся. Планируемую ставку вы укажете при переводе потребности в «Найм».»
- Прогресс: шаг «Профиль сотрудника, исполнитель» (без «ставка»); остальное как раньше.
- Отказ Jira, истёкшая сессия, успех — без изменений (KON-79).

### 2. Диалог «Найм» (`StatusForm`, action = hire)
Состояния по порядку: «Запрашиваем доступные действия в Jira…» (KON-96) → форма | «Действие недоступно» → «Переводим потребность в «Найм»…» → успех (окно закрывается, потребность перечитывается).
- Заголовок «Найм»; контекст «Потребность 5919 · SA-590 · сейчас «<статус>»»; подсказка «Поля ставки обязательны в Jira. Валюта, единица и НДС предзаполнены из потребности — проверьте их. Значения справочников берутся из Jira.»
- Поля в порядке Tab: «Планируемая ставка» (текст, `inputMode=decimal`, placeholder «например, 3 800», formatting как `parseRate`; под полем — «В потребности: 3 600 RUB с НДС, «от производства».» или «В потребности: ставка не указана.»); строка ориентира; ряд из трёх списков: «Валюта», «Единица измерения», «Включает НДС» (справочники Jira, значения по id, предзаполнение из потребности; все `*`).
- Обязательность ставки: `*` и ошибка «Укажите планируемую ставку: в потребности «Кто предлагает ставку» = «от производства».» только при «от производства»; иначе поле без `*`, в подсказке: «Необязательно: ставку предлагает клиент.» Проверка до отправки, после неё фокус на первом ошибочном поле. Пустой список без предзаполнения — «Выберите…», ошибка «Выберите значение».
- Ориентир (`.bench`, пунктирная рамка, FR-019): «Ориентир за 6 мес. · рубли, час, с НДС · среднее 3 450 · медиана 3 400 · по 41 потребности» + «Только справка: значение не подставляется и не проверяется.» Пересчитывается при смене «Валюта»/«Единица измерения». Запрос не блокирует форму. Состояния: «Считаем ориентир…»; «Ориентир сейчас недоступен — на перевод в «Найм» это не влияет. Повторить»; «Ориентира нет: за 6 мес. не было потребностей со ставкой в <валюте> за <единицу>.»; «Ориентир появится после выбора валюты и единицы измерения.»
- Кнопки: «Отмена» (secondary) и основная «Перевести в «Найм»». Отказ Jira — рамка `--err`, текст как есть, введённое сохранено, «Повторить»; сессия истекла — блок «Сессия Jira истекла» с «Пароль Jira» в окне, «Войти и продолжить»; закрыть во время отправки нельзя.
- Esc закрывает (кроме отправки); видимый фокус; Enter в полях — отправка.
- Передача в Jira: ставка (число), валюта, единица, НДС — по id (FR-018, FR-011); при пустой необязательной ставке поле не отправляется.

## Данные и API
- Ориентир (KON-95): нужен метод со среднее/медиана/размер выборки по параметрам валюта, единица, период (по умолчанию 6 мес.); «с НДС», считается по валютам отдельно (FR-019). **Допущение**, формат не зафиксирован; задача KON-95 сформулирована под окно «Назначить» и подлежит перепривязке к диалогу «Найм».
- Справочники полей и предзаполнение — из `GET status-actions` при открытии диалога (как сейчас).
- Если метода ориентира нет — показывается «Ориентир сейчас недоступен…», перевод работает.

## Критерии приёмки UI
1. В окне «Назначить» нет поля ставки; есть подсказка о том, что ставка вводится при «Найм»; для «от производства» — дополнительное предложение.
2. Подтверждение назначения не содержит строки «Ставка»; есть блок «Ставка не передаётся…»; запрос назначения не содержит ставки.
3. Диалог «Найм» открывается состоянием «Запрашиваем доступные действия в Jira…»; при отсутствии перехода — «Действие недоступно» с текстом про права/воркфлоу.
4. Форма «Найм»: «Планируемая ставка», ориентир, «Валюта», «Единица измерения», «Включает НДС»; три списка предзаполнены из потребности.
5. При «от производства» пустая ставка не уходит: ошибка под полем; при «от клиента» уходит без ставки.
6. Не выбранный обязательный список даёт ошибку до отправки.
7. Ориентир: среднее и медиана для выбранных валюты/единицы; при ошибке/пусто — текст и «Повторить» (при ошибке), перевод не блокируется.
8. Отказ Jira — текст как есть, введённое сохранено, «Повторить»; сессия истекла — пароль в окне без потери данных.
9. Обе темы, 1280 и 1024, высота окна 400px (шапка/футер на месте, тело прокручивается); Tab-порядок, Esc, видимый фокус.
