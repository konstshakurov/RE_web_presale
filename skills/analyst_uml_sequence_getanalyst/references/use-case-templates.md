Возвращать выбранный шаблон без дополнительных советов и вопросов. Перед каждым шаблоном
обязательно писать точную фразу на языке пользователя, сохраняя смысл:

> Скопируйте этот шаблон, чтобы в следующем сообщении запросить генерацию кода PlantUML

## Use Case Template - with Example

```text
Use Case:
Запись пациента на приём в поликлинику

Роли пользователей:
- Пациент
- Сотрудник регистратуры

Приложения и системы:
- Веб-приложение поликлиники (Frontend)
- АРМ сотрудника регистратуры (Frontend)
- Сервер-приложение поликлиники (Backend)
- База данных поликлиники
- Внешний СМС-шлюз

Предусловия:
- Расписание врачей загружено в систему.
- У пациента есть номер телефона.

Основной сценарий:
1. Пациент открывает веб-приложение поликлиники.
2. Пациент выбирает специальность врача и дату приёма.
3. Веб-приложение запрашивает у Backend доступные интервалы приёма.
4. Backend получает доступные интервалы из базы данных и возвращает их веб-приложению.
5. Пациент выбирает врача и свободное время, вводит свои данные и подтверждает запись.
6. Веб-приложение отправляет на Backend запрос на создание записи.
7. Backend повторно проверяет доступность выбранного времени и сохраняет запись в базе данных.
8. Backend передаёт во внешний СМС-шлюз данные для отправки подтверждения пациенту.
9. Веб-приложение показывает пациенту сообщение об успешной записи.

Альтернативные сценарии и ошибки:
3А. Если свободных интервалов нет, веб-приложение сообщает об этом пациенту.
7А. Если выбранное время уже занято, Backend не создаёт запись и веб-приложение предлагает
    пациенту выбрать другое время.
8А. Если СМС-шлюз недоступен, запись остаётся созданной, а ошибка отправки фиксируется в логе.
```

При локализации не менять структуру, нумерацию и смысл примера. Перевести все заголовки,
плейсхолдеры, роли, системы, шаги и сообщения.
