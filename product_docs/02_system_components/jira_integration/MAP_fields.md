# MAP — поля Jira, справочники, переходы

Источник: `backend/app/sync/mapping.py`, `backend/app/assign/service.py`, `backend/app/integrations/jira/port.py`.

## Поля потребности (проект ANALYTICS, тип «Аналитик») → кэш `jira_need`

| Поле Jira | Смысл | Кэш / использование |
|---|---|---|
| `key`, `summary`, `description` | ключ, заголовок, описание | `jira_key`, `title`, `description` |
| `status` | статус (19 значений) | `status`; группы статусов — `status_groups` |
| `created`, `updated` | время (формат `2026-09-30T13:04:48.495+0400`) | `jira_created_at`, `jira_updated_at`; `updated` — водяной знак опроса |
| `assignee`, `reporter` | исполнитель, автор | `assignee`, `author` |
| `customfield_10101` | Epic Link (канонический для клиента; открытый вопрос — `customfield_11032`) | `epic_key` |
| `customfield_10811` | требования (текст) | `requirements_text` |
| `customfield_19201` | тип договора: «Прямой контракт» / «Субподрядчик» | `contract_type` |
| `customfield_20809` | ставка | `rate_amount` |
| `customfield_20810` | НДС (Да/Нет) | `rate_includes_vat` |
| `customfield_20811` | валюта: «руб.», usd, kzt → RUB, USD, KZT (EUR/GBR схема не принимает → `rate_dropped`) | `rate_currency` |
| `customfield_20812` | единица (час) | `rate_unit` |
| `customfield_21105` | кто предлагает ставку («от производства» / клиент) | `rate_proposer` |
| `customfield_10707` | «Профиль сотрудника» (тип user), значение — логин, нижний регистр; **не** `11515` (числовой id) | `employee_login` → `employee_key` (карточка cv_db с этим `jira_login`, только если однозначная) |
| `parent`, `priority` | Jira не отдаёт | не используются |

Поля, которые Jira не прислала, не считаются ошибкой (`.get()`).

## Поля сотрудника (тип «Epic» в ANALYTICS) → `cv_db`

| Поле Jira | Смысл |

## Поля записи

| Поле | Где | Значение |
|---|---|---|
| `assignee` | PUT или поле перехода 21 | `{"name":"<логин пользователя сессии>"}` (FR-009) |
| `customfield_10707` | PUT или поле перехода 21 | `{"name":"<логин сотрудника>"}` |
| `customfield_11602` «Поддержка» | поле перехода 21 | всегда «Не требуется» (id — из `allowedValues` перехода) |
| `customfield_11506` «Нужно предоставить CV» | PUT (обход CR-006) | `{"value":"Нет"}` на время перехода, затем `{"value":"Да"}` |
| `customfield_16100` «Причина отсутствия кандидата» | поле перехода 171 | `{"id":"<id из allowedValues>"}` — поле ищется по имени, id запасной |
| `customfield_20810/20811/20812` | поля перехода 801 «Найм» | предзаполняются из потребности (НДС, валюта, единица); ставка на переходе **не** передаётся (CR-008) |
| `customfield_20809/20810/20811/20812/21105` | ScriptRunner (J12) | ставка и справочники (см. `API_jira_endpoints.md`) |

## Статус-действия приложения ↔ переходы Jira (FR-011, FR-026)

| Действие | Целевой статус Jira | Известный id перехода | Поля / условия |
|---|---|---|---|
| `search` | «Поиск кандидата» | — | по списку Jira |
| `hire` | «Найм» | 801 | НДС/валюта/единица предзаполнены; ставка не вводится |
| `no_candidates` | «Кандидатов нет» | 171 | причина (16100) и комментарий обязательны |
| (назначение) | «Кандидат назначен» | 21 | профиль, исполнитель, «Поддержка»; комментарий всегда; обход 11506 |

Переход ищется по **имени целевого статуса** в ответе `get_transitions`; id в коде не зашиты. Если Jira не предлагает переход — действия нет в списке (универсального списка нет).
