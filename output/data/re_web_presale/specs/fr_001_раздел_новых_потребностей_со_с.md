## Формулировка

> _Формулировка: «Система ДОЛЖНА [действие]...»_

Система ДОЛЖНА отображать в отдельном разделе потребности из Jira (проект ANALYTICS, тип задачи «Аналитик»). Для каждой потребности ДОЛЖНЫ показываться: ключ, название, статус, клиент/эпик, тип контракта (Прямой контракт / Субподрядчик), ставка. Ставка ДОЛЖНА показываться вместе с валютой, признаком «Включает НДС» и единицей измерения (поля Jira: Планируемая ставка 20809, Включает НДС 20810, Валюта 20811, Единица 20812); пустая ставка допустима и показывается как «не указана».

## Обоснование

Единая точка входа РО в потребности направления Аналитики вместо ручного просмотра Jira (BN-001).

## Ограничения и допущения

Источник данных — локальный кэш (см. FR-028); списки из кэша ≤ 2 с.
