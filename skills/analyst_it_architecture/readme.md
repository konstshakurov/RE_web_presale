# IT Architect — Генератор архитектурных артефактов

Продвинутый скилл для генерации полного пакета архитектурных артефактов на основе бизнес-требований. Артефакты автоматически записываются в структурированную файловую систему.

## Структура

```
it-architecture-skill/
├── SKILL.md              # Основные инструкции для AI (обязательный)
├── references/           # Справочные материалы (загружаются по мере необходимости)
│   ├── template.md       # Шаблоны вывода для каждого типа артефакта
│   └── api-docs.md       # Справочник по фреймворкам (ARC42, TOGAF, C4, ADR)
├── scripts/              # Вспомогательные скрипты
│   └── export.ps1        # Создание файловой структуры артефактов
└── assets/               # Статические файлы и конфигурация
    └── profiles.json     # Шаблоны систем, профили глубины, авто-определение
```

## Возможности

- **Автоматическая классификация** системы по описанию
- **Выбор шаблона** на основе домена и контекста
- **Генерация полного пакета** архитектурных артефактов с записью в файлы
- **Умные уточнения** — вопросы с вариантами ответов, только при необходимости
- **Несколько профилей глубины** — от быстрого обзора до enterprise-уровня
- **File-first подход** — все артефакты сохраняются в структурированную директорию через `export.ps1`

|----------|----------|
| C4 Context | Контекстная диаграмма системы |

| System Pattern | Архитектурный паттерн |

| NFR Matrix | Матрица нефункциональных требований |
| Technology Stack | Рекомендованный стек технологий |

## Шаблоны

| Шаблон | Для чего |
|--------|----------|
| Web Application | Веб-приложения (SPA + backend) |
| Microservices | Распределённые микросервисы |
| API Service | API-first бэкенд-сервисы |
| Enterprise System | Корпоративные системы (ERP, CRM) |
| Data Platform | Data-интенсивные системы |
| Real-Time System | Системы реального времени |
| Mobile Backend | Бэкенд для мобильных приложений |

## Профили

| Профиль | Глубина | Когда использовать |
|---------|---------|-------------------|
| Quick | Поверхностный | Прототипы, MVP, внутренние инструменты |
| Standard | Средняя | Большинство проектов (по умолчанию) |
| Enterprise | Глубокий | Регулируемые отрасли, крупные команды |
| Startup | Средняя | Стартапы, малые команды, быстрый рост |

## Использование

Просто опишите систему на свободном тексте. Скилл сам:

1. Определит тип системы и профиль глубины
2. Задаст уточняющие вопросы (если нужно)
3. Создаст файловую структуру через `scripts/export.ps1`
4. Сгенерирует и запишет артефакты в файлы

### Результат

Каждый артефакт сохраняется в отдельный файл с нумерацией по приоритету:

```
[Название-системы]/
├── _metadata.md
├── 01-architecture-blueprint.md
├── 02-context-diagram.md
├── 03-container-diagram.md
├── 06-api-specification.md
├── 07-data-model.md
├── 10-security-architecture.md
└── 14-architecture-decision-records.md
```
