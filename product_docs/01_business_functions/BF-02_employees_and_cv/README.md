## Известные расхождения
Расхождений нет. DD-001 v1.1 (CR-009, 26.10.2026): «сессионный токен Jira».

Правила РО (CR-012, CR-014; решения владельца 28.10.2026):
* Фильтр «РО»: «Все» (по умолчанию), имена по алфавиту, «Без РО» последним. «Не назначен» в Jira = «Без РО» (в БД NULL).
* В списке РО не показываются неактивные в Jira (active = false) и скрытые настройкой окружения; на данные сотрудников и фильтр по логину это не влияет.
* Смысловой поиск («Резюме») никогда не охватывает сотрудников в статусе «Уволен»; область ограничена остальными фильтрами. В обычных списках «Уволен» - отдельный тумблер «Уволенные».
* Фильтр по технологии на «Сотрудниках» не добавляется; РО в карточке сотрудника не показывается.

Привязка статусов к цветам (`frontend/src/lib/statusTone.ts`, `design/KON-149/decision.md` п. 3) подтверждена владельцем 29.10.2026.

Статусы требований FR-002, FR-032 в графе - `pending_approval` (пакет 5.5 APKG-CR011-016-CLOSE ждёт решения владельца). Отдельная БФ для РО не заводилась: РО - часть BF-02 (вопрос владельцу).
