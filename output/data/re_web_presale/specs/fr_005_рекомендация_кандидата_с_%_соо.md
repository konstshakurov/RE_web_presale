## Формулировка

> _Формулировка: «Система ДОЛЖНА [действие]...»_

Система ДОЛЖНА по запросу пользователя («Сопоставить», FR-036) оценивать соответствие сотрудников выбранной потребности: процент и краткое текстовое обоснование, рассчитанные LLM по Основному CV (FR-027) и требованиям потребности — опыт в годах, отрасли, инструменты, опыт в системах, профессия. В оценку ДОЛЖНА учитываться свободная заметка о сотруднике (FR-033, например «не подключать в ЛеманаПРО»). Оцениваются только сотрудники в статусах, допустимых для назначения (FR-002) и имеющие Основное CV. Результат — рекомендация; решение принимает пользователь. Метрик качества не задаётся (ISS-006). Для снижения нагрузки на LLM система ДОЛЖНА сначала отобрать сотрудников детерминированно (по технологиям, статусу), а LLM оценивать только отобранных (предложение); результат кэшируется по связке «потребность + Основное CV + модель» и пересчитывается при изменении потребности или CV.

## Обоснование

Цель BG-001: выбор кандидата за 1 минуту. Предварительный отбор и кэш делают отклик достижимым на ~80 сотрудниках.

## Ограничения и допущения

Версия 2. LLM по умолчанию Qwen; внешняя — только обезличенный текст (FR-023); таймаут 120 с (NFR-010).
