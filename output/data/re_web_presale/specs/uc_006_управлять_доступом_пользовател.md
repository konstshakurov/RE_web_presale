## Основной сценарий (Happy Path)

1. Администратор добавляет или отзывает LDAP-аккаунт в списке доступа.
2. Администратор задаёт или меняет API Key и URL внешней LLM, провайдер по умолчанию, таймаут.
3. Система шифрует и сохраняет значения.

## Альтернативные сценарии

1а. Отзываемый пользователь в сессии — его сессия прекращается.

## Сценарии исключений

2а. Тест подключения к LLM не прошёл — система показывает ошибку, значения не сохраняются.
