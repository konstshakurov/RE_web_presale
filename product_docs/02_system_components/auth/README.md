# Аутентификация и доступ — паспорт компонента (SRV)

Уровень детализации: **обзорный** (архитектура ADR-006/008, маршруты и модули кода). Построчной сверки с кодом и диаграмм нет — следующий шаг по необходимости (SEQ входа см. в `../jira_integration/seq/seq1_login_jira_session.puml`).

| Атрибут | Значение |
|---|---|
| Назначение | Вход по корпоративному LDAP, список допущенных, серверные сессии, администрирование пользователей, шифрование секретов |
| Код | `backend/app/auth/` (`router.py`, `admin.py`, `deps.py`, `sessions.py`, `ldap_adapter.py`, `ldap_port.py`, `hooks.py`), `backend/app/secrets/` (`crypto.py`, `store.py`), `backend/app/jira_session/` |
| Бизнес-функции | BF-06 |
| Требования | FR-021, FR-024, FR-025, UC-005, UC-006, NFR-006 |
| Архитектурное решение | ADR-006 (AES-256-GCM, ключ в env), ADR-008 (LDAP bind + список + сессии, TTL 8 ч), ADR-005 (сессия Jira) |

## Эндпоинты

| Метод и путь | Назначение |
|---|---|
| `POST /auth/login` | LDAP bind → проверка списка допущенных (`app_user.active`) → серверная сессия (cookie HttpOnly, SameSite=Lax) → хук создания сессии Jira |
| `POST /auth/logout` | отзыв сессии (CSRF) |
| `GET /auth/me` | профиль, роль, `jira_status` |
| `POST /auth/jira-relogin` | повторный ввод пароля Jira |
| `GET/POST/PATCH /admin/users…` | список допущенных (админ), немедленный отзыв (FR-021) |

Подробные контракты Jira-части — `../jira_integration/API_app_endpoints.md`.

## Ключевые правила
* LDAP: прямой bind `uid={login},cn=users,cn=accounts,dc=simbirsoft,dc=dev` (параметры — env, вне Git); TLS для LDAP не используется (`ldap://`) — принятое ограничение внутреннего контура.
* Нет в списке допущенных → тот же отказ 401 (не раскрывать причину), даже при верном LDAP.
* Отзыв доступа действует немедленно: активность пользователя проверяется на каждый запрос.
* Пароль живёт только в памяти запроса; в БД — хэш идентификатора сессии, не сам идентификатор.
* Секреты (сессионный токен Jira, ключи LLM) шифруются AES-256-GCM, `APP_ENC_KEY` — только в env; в логах — фильтр секретов (`logging_setup.redact`).
* LDAP недоступен → 503 с отдельным текстом.
