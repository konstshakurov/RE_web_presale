## Что меняется

Было: при назначении кандидата система **всегда** добавляла в потребность
комментарий «Кандидат назначен через re_web_presale» (шаг «Комментарий и статус»).

Стало: **авто-комментарий не добавляется**. Переход в «Кандидат назначен» уходит
без комментария; комментарий в потребность появляется только если пользователь сам
заполнил поле «Комментарий» (скрининг, сопроводительное письмо и т.п.).

## Обоснование владельца

Системные служебные комментарии засоряют потребность в Jira; пользователю
достаточно собственного текста по желанию.

## Реализация

`backend/app/assign/service.py` (шаг перехода): значение по умолчанию убрано;
`comment` уходит только при непустом пользовательском тексте. Тесты `test_assign.py`
(60) зелёные, изменений критериев не требуется.

## Критерии приёмки

1. Назначение без заполненного «Комментарий» → в Jira нет нового комментария.
2. Назначение с текстом → комментарий = текст пользователя (как раньше).
3. Прочие шаги (поля, вложения, переход, ставка) — без изменений.
