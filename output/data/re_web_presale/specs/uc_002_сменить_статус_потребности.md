## Общая информация

| Атрибут | Значение |
|---------|----------|
| Актор (primary) | РН / РО / Presale-менеджер |
| Акторы (secondary) | Jira |
| Предусловие | Пользователь авторизован в Jira; потребность открыта. |
| Постусловие | Статус потребности в Jira изменён; в кэше приложения обновлён. |
| Триггер | Пользователь выбирает «Сменить статус». |

## Основной сценарий (Happy Path)

1. Система запрашивает у Jira допустимые переходы из текущего статуса с обязательными полями.
2. Система показывает переходы.
3. Пользователь выбирает переход (например, «Кандидатов нет» или «Найм») и заполняет обязательные поля.
4. Система отправляет переход в Jira от имени пользователя.
5. Система обновляет статус в приложении.

## Альтернативные сценарии

3а. Для «Кандидатов нет» пользователь выбирает причину из справочника Jira и вводит комментарий (FR-011).

## Сценарии исключений

4а. Jira отказала (403 и др.) — система показывает причину как есть.

## Бизнес-правила и ограничения

BR-001, BR-008.
