## 5. Состояния

| Состояние | Реализация в коде |
|---|---|
| Ошибка | `.error` (`--err`), `role="alert"` |
| Пусто | `.empty` — панель с рамкой |
| Загрузка | `.spinner` + текст; на кнопках `disabled` (`opacity .5–.6`) |
| Disabled | `opacity: .5 / .6`, `cursor: default` |
| Предупреждение/Jira | `.jira-banner` — полоса под шапкой, нижняя граница `2px --warn` |
| Бейджи статуса | `.badge`, `.badge--paused/stale` (`--warn`), `.badge--reauth/error` (`--err`) |
| Hover / focus | отдельных стилей нет: используется браузерный `:focus-visible`, hover-стилей у кнопок нет |
| Активный пункт | меню: белый текст + линия `3px`; вкладки: `--text` + линия `--accent`; чип: заливка `--accent` |

## 6. Описание существующего интерфейса («вариант 0»)

Прототип «как сейчас»: `design/KON-78/variant_0_current.html`.

**Шапка (`Header.tsx`)** — одна на все страницы, включая вход. Слева логотип (`assets/logo.png`,
в шапке без текста), затем меню «Потребности», «Сотрудники», «Резюме», «Настройки»
(«Настройки» только `role=admin`, FR-031), справа сокращённое имя пользователя
(`shortName`: имя+фамилия без отчества) и кнопка «Выйти». На странице входа (пользователь
не вошёл) показан только логотип. Активный пункт — белый текст с подчёркиванием.

**Каркас (`Layout.tsx`)** — `Header` → `JiraBanner` (полоса «нужен пароль Jira», FR-029) →
`<main class="content">` с `<Outlet/>`. Ширина контента не ограничена. Стартовая — «Потребности».

**Вход (`LoginPage.tsx`)** — шапка (логотип) + карточка 320px: логотип 120px, заголовок
«Вход», поля «Логин» и «Пароль» (метки видимы, `required`, `autocomplete`), кнопка «Войти»,
ошибка под полями (`role="alert"`) с текстом бэкенда: «Неверный логин или пароль, либо нет
доступа» (401) или «Сервис входа временно недоступен, повторите позже» (503). На время
запроса кнопка `disabled`, подписи «загрузка» нет. Пароль не хранится в state. После входа —
возврат на прежнюю страницу (`location.state.from`) или `/needs`.

**Разделы:** «Потребности» (фильтры-чипы статусов, панель синхронизации, таблица с
раскрывающимися деталями, пагинация), «Сотрудники» (сетка карточек), «Резюме» (панель
фильтров + карточки/файлы, модалка просмотра CV), «Настройки» (вкладки: доступ, LLM, JQL,
группы статусов, НДС/лимит файла). «Нет доступа» — отдельная страница для не-админа.

**Наблюдения (для вариантов):**
1. На странице входа логотип показан дважды (шапка 40px и карточка 120px).
2. Нет подписи продукта рядом с логотипом: в шапке `alt="RE"`.
3. Нет индикации «на какой я странице» кроме подчёркивания; нет заголовка-контекста у меню.
4. Нет hover-стилей; фокус — браузерный.
5. Для входа нет явных состояний: пустые поля (только нативная валидация), «проверяем
   сессию» (`loading`), «сессия истекла» — пользователь молча попадает на форму.
6. Ориентировочный контраст (проверить Dev по факту): белый на `#0b8a5c` ~4.4:1 (на грани
   4.5), белый на `--accent` тёмной темы `#3e8ef7` ~3.3:1 (ниже 4.5) — активный чип
   `.filter__item--active`.
7. Литералы цветов (раздел 2) не вынесены в токены; `#3e8ef7` в меню дублирует `--accent`.
