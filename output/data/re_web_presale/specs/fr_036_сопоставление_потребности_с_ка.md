## Формулировка

> _Формулировка: «Система ДОЛЖНА [действие]...»_

По кнопке «Сопоставить» в столбце «Требования» система ДОЛЖНА запустить сопоставление (FR-005) и показать в столбце «Кандидаты» список подходящих сотрудников, отсортированный по убыванию % совпадения. Для каждого кандидата показываются: ФИО, статус сотрудника, % совпадения (цветовая шкала), значок заметки (FR-033), кнопки «Резюме» (открыть Основное CV, FR-037) и «Назначить» (FR-008). Первоначально показываются 10 лучших, остальные — по «Показать ещё». Подсказка с обоснованием оценки показывается по клику на %. Повторное открытие потребности показывает сохранённый результат с датой расчёта и кнопкой «Пересчитать». Если подходящих нет — сообщение; пользователь может перейти к смене статуса «Кандидатов нет» (FR-011).

## Обоснование

Часть 2 ФТ; по референсу. Кэш результата — быстрый повторный просмотр и экономия LLM.

## Ограничения и допущения

Таймаут 120 с (NFR-010): пока идёт расчёт — индикатор; результат не блокирует остальной интерфейс.
