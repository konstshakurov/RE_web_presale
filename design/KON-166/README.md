## Что изменилось по правкам владельца 25.11.2026 (в вариантах A и B)

**Раунд 3 (только прототипы):** вес текста 450 (шапка системы — 500), строки таблицы 13px
(в B — 12px по оси плотности), кнопки внутри таблицы — 25px с весом 450, облачка статусов —
полностью круглые (радиус 999px, как у облачка «92%»).

**Раунд 4 (только прототипы):** шапка системы — вес 450 и белый цвет невыделенных разделов
и имени пользователя (активный раздел — как было); межстрочный интервал −20% везде
(1.45 → 1.16); «Пересчитать» и селект «LLM по умолчанию» — 25px, шеврон селекта сдвинут от
края (отступ как у «Сопоставить ⌄»); вторичные строки «Ставки» («с НДС», «от произв.»,
«от клиента») — 13px (в B — 12px), как основной шрифт таблицы; «Изменить ⌄» прижата к левой
границе столбца «Статус» (блочный flex, левый край на одной линии с облачком); чипы групп
стали ниже (~3–4px) за счёт нового межстрочного (отступы 7px сохранены).

**Раунд 4а (отменён владельцем):** выравнивание «Изменить ⌄» по слову внутри облачка
(сдвиг 10px) и сдвиг меню — отклонено; в прототипах возвращено состояние раунда 4:
«Изменить ⌄» от левого края столбца «Статус», на одной линии с краем облачка; меню под кнопкой.

**Раунд 5 (только прототипы):** невыделенные чипы групп статусов и быстрые кнопки дат
(светлая тема) — заливка **#f7f9fe** (значение владельца) вместо голубой #e8f0fd, контур —
серый `--border`, тот же токен, что у поля поиска (контур теперь явно виден); выделенные
состояния не тронуты (синий чип, «30 дней» с синим контуром); disabled-вид «Сбросить даты»
определён как невыделенное с приглушённым текстом (в прототипах даты заданы — кнопка
активна); тёмная тема не менялась.

**Раунд 6 (только прототипы):** в раскрытом блоке кандидатов убрана строка заголовков
колонок («Кандидат», «Совпадение», «Рекомендации») — колонки контента сохранены, отступы
перепроверены; в шапке системы иконка выхода — белая; заглушка логотипа заменена на
логотип текущей реализации (ассеты KON-135 `logo_head.svg` + `logo_wordmark.svg`,
скопированы в `design/KON-166/`, размеры как в Header.tsx/styles.css: head 34px,
wordmark 21.5/48 от head — прототип остаётся самодостаточным внутри своей папки).

| Правка | Как применено |
|---|---|
| Гарнитура не меняется; шапка системы — вес 450, белый цвет невыделенных пунктов | system-ui; навигация и имя пользователя — 450, цвет белый; активный раздел — как было |

| Строки таблицы −2 пункта → финально 13px | 14px → **13px** в A (в B — 12px по оси плотности); читаемость сохранена |
| Шрифт «Ставки» — как во всей строке | `.rate-main` наследует размер строки (13px), одна строка nowrap, «—» вместо «не указана» |
| Высота шапки таблицы — прежняя | п. 3.12 отменён: `th` 10px/13px, как в текущей реализации |
| «Обновить» без иконки внутри | иконка убрана из кнопки; осталась перед штампом «актуально на…» (п. 3.2 отменён) |
| Чипы групп — синий, шрифт 450, не жирный | цвет из первой волны оставлен, начертание среднее (450) |

| Облачка — прежние цвета, полностью круглые | пастельный фон + цветной текст (statusTone: ok/info/err/warn), вес 450, радиус 999px (раунд 3); тёмная тема — как сейчас |
| Высота кнопок в таблице = высоте облачка | «Сопоставить», «ROS», «Резюме», «Назначить», «Пересчитать» — 25px, шрифт 450 |
| Затемнение по контуру у таблицы | тот же контурный Shadow, что у блока фильтров (`0 1px 3px`, светлая тема; в тёмной — нет) |
| Раскрытые блоки — белые на голубом, раскладка прежняя | цвет фона `--row-sel` + белые карточки сохранены; **внутренняя раскладка возвращена к реализации**: навыки и заметка — в колонке «Совпадение» (под процентом), обоснование и «Чего не хватает» — в «Рекомендациях», без строки заголовков колонок (убрана раундом 6); блок правил — заголовок во всю ширину, kv-таблица слева, карточки комментариев справа (скрин «Сотрудники - правила») |

Состояния сохранены: открытое меню «Изменить ⌄» с иконками (состав по FR-026 для показанного
статуса), активные шевроны ⌃ («Правила ⌃» 6012, «8 кандидатов ⌃» 6009), ставка «—» и
«2 240 RUB» в одну строку шрифтом строки, чип «Суб», строка «Отказ по кандидату» без кнопки

## Сравнение вариантов

| | **A — по референсу, inline-блоки** | **B — поповеры + компактная плотность** |
|---|---|---|
| Идея | Референс + поправки; раскрытие «Правила»/кандидатов — широкой полосой под строкой, как сейчас | Тот же стиль, но раскрытие — плавающая панель под ячейкой; строки плотнее (12px) |
| Плюсы | Максимальное совпадение с референсом; минимум изменений поведения — предсказуемо для QA; широкие блоки показываются просторно | Строка и позиция прокрутки не «прыгают»; можно сверить несколько строк подряд; на 2000+ строк видно больше без прокрутки |
| Минусы | Открытый блок сдвигает таблицу вниз; при сверке строк теряется контекст | Поповеры перекрываются; позиционирование и закрытие (клик вне, Esc) — дополнительный код; плотные строки менее «воздушны» |
| Цена для Dev | Минимальная: переоформление существующих `needs__details`-строк + новые токены (вес 450, контур) | + позиционирование поповера (CSS absolute в ячейке), клик-вне/Esc, `aria-haspopup="dialog"`; ~1–2 дня сверху |

Вариант 0 — только точка сравнения, его не выбирают.

## Открытые вопросы (закрыты решением «оставить как сейчас» — перенесены в «Вне объёма» decision.md)

1. **Пагинация** — осталась «Назад/Вперёд» + «На странице», как сейчас; нумерация из
   референса не делается (без ответа владельца — вне объёма).
2. **Тёмная тема пилюль** — остаётся «как сейчас» (FR-038 v1.5 «тёмная тема НЕ ДОЛЖНА
   меняться»); в реализации тёмные облачка — фон `--panel-2`, цветной текст.
3. **Точные цвета референса** — hex подобран прототипом (PNG-исходника нет); при появлении
   исходника макета — сверка отдельным пунктом.
4. **Чип «Суб»** — появляется только если группа «Субподряд» настроена в «Настройках»
   (FR-035); состав групп конфигурируемый.
5. **Стрелка сортировки ▼ у «Создана»** — оставлена как сейчас.

(Вопрос о шевроне в облачке статуса снят — решён владельцем: шеврона нет, FR-011 v1.5.)
