# KON-166 (Pre.UX-16) — UI раздела «Потребности» по референсу владельца (CR-022, REW-46 / BF-01)

> **Статус: approved 25.11.2026** — владелец утвердил вариант A («Получилось отлично.
> Сохраняй. В разработку возьмем в пятницу»). Решение для Dev — `decision.md`.

## Кто и зачем

Пользователь — руководитель направления аналитики (и его команда) ежедневно работает со
списком потребностей из Jira: фильтрует, меняет статусы, сопоставляет кандидатов. Раздел
открывается много раз в день, работа потоковая — приоритет плотности и предсказуемости.

Задача: привести вид раздела «Потребности» к референсу владельца от 24.11.2026
(скрин 3 — эталон вида, скрин 4 — эталон меню статусов) по утверждённым пунктам CR-022 3.1–3.12.
Функциональное поведение не меняется — меняется элемент управления и стиль.

## Требования (ID, версии, baseline v2.9)

- **FR-011 v1.5** — столбец «Статус»: облачок статуса (пастельный, без шеврона, шрифт 500),
  под ним кнопка «Изменить ⌄», выпадающее меню ТОЛЬКО доступных Jira-переходов (FR-026),
  у каждого пункта иконка статуса (эталон — скрин 4, вид пунктов); меню с клавиатуры:
  видимый фокус, aria-expanded, открытие/закрытие/выбор без мыши. Для статусов без переходов
  (включая «Отказ по кандидату») кнопки нет.
- **FR-034 v1.3** — состав столбцов как в текущей реализации (скрин 2, решение владельца):
  Ключ, Автор, Название, Статус, Клиент, Контракт, Ставка, Кандидаты, Создана. Блок фильтров:
  поиск с очисткой (X); дата-диапазон по дате создания (столбец «Создана») «дд.мм.гггг —
  дд.мм.гггг» с календарём + быстрые кнопки «Сегодня», «7 дней», «30 дней», «Сбросить даты»;
  кнопка «Обновить» без иконки внутри (иконка обновления — перед штампом «актуально на…»);
  текст JQL (только чтение). Ставка «2 240 RUB» в одну строку шрифтом строки, «—» вместо
  «не указана».
- **FR-035 v1.2** — чипы групп статусов: синий и яркие пилюли как предложено в design/KON-166,
  шрифт средний (500), не жирный; «Субподряд» → «Суб».
- **FR-036 v1.3** — кнопка «Сопоставить ⌄», шеврон на одной линии с текстом, активное
  состояние ⌃; поведение сопоставления не меняется.
- **FR-038 v1.5** — вес 400→500 глобально (гарнитура system-ui не меняется); шрифт строк
  таблицы −2 пункта; чипы статусов — прежние пастельные цвета, без шеврона, шрифт 500;
  высота кнопок внутри таблицы = высоте облачка статуса, шрифт 500; радиусы контейнера
  таблицы по референсу; затемнение по контуру — как у блока фильтров; раскрытые блоки —
  белые на голубом фоне, внутренняя раскладка текста (заметки, навыки) — как в реализации;
  шевроны «Правила ⌄»/«N кандидатов ⌄» с ⌄→⌃; кебаб-меню НЕ делать; п. 3.2 (иконка в
  «Обновить») и п. 3.12 (шапка −20%) ОТМЕНЕНЫ владельцем 25.11.2026. Тёмная тема не меняется.

## Контекст

Светлая тема — палитра А2 (design/KON-149, approved). Чипы статусов — пастель
(`statusTone.ts`), строки таблицы — hover/selected с левой полосой 3px. Кнопка ROS
(рентабельность, FR-041/BF-12) уже реализована — показывается как есть, не меняется.
Кебаб-меню из референса не реализуется (3.11). Состав столбцов — по скрину 2 (уточнение
владельца 24.11.2026), скрин 3 — эталон стиля, а не состава.

## Ограничения

- Стек: React + обычный CSS (`styles.css`), без UI-библиотек; новые зависимости не вводим.
- Токены меняются только через `decision.md` после апрува владельца (значения сейчас
  предлагаются прототипом).
- Данные в прототипах вымышленные обезличенные; ФИО/логины из референсов и `input/` не копируются.
- Область записи — только `design/KON-166/`; код продукта, `output/`, `product_docs/` не трогаются.

## Допущения (помечены явно, не из требований)

1. Синий акцент чипов групп и кнопок (#1a66d9 и производные) — предложение UX из первой
   волны, принято владельцем 25.11.2026 (FR-035 v1.2). Точные hex исходника макета
   недоступны (PNG) — при наличии исходника сверить значения до decision.md.
2. Тёмная тема — в текущем виде (FR-038 v1.5 «тёмная тема НЕ ДОЛЖНА меняться»): облачка
   статусов на `--panel-2` с цветным текстом, чипы групп как сейчас.
3. Шеврон внутри облачка статуса удалён — решение владельца 25.11.2026 (FR-011 v1.5);
   интерактивен только «Изменить ⌄».
4. Состав групп чипов в прототипе — демонстрационный (включая чип «Суб» для показа
   сокращения); реальный состав настраивается в «Настройках» (FR-035).
5. Меню «Изменить ⌄» показано открытым для статуса «Требуется кандидат» с пунктами
   «Поиск кандидата», «Найм», «Кандидатов нет» — переходы по FR-026 для этого статуса.
   Скрин 4 задаёт вид пунктов (иконки), а не состав меню.
6. Пагинация оставлена в текущем виде («Назад/Вперёд», «На странице») — вне скоупа
   поправок; стиль нумерации из референса — открытый вопрос владельцу.
7. «Строки −2 пункта» по раундам уточнено владельцем: финально строки таблицы — 13px
   (вариант A; в B — 12px по оси плотности). Кнопки внутри таблицы и селект «LLM» — 25px
   (селект с шевроном с отступом от края). Облачка статусов — полностью круглые (радиус
   999px), высота облачка ≈ 25px = кнопкам. Вес текста — 450, в том числе в шапке системы
   (навигация и имя пользователя — 450, цвет белый; активный раздел — тёмный на светлом).
   Межстрочный интервал — 1.16 (−20% от 1.45); чипы групп ≈30px высотой (−3–4px).
8. «Затемнение по контуру» (светлая тема) — `0 1px 3px rgba(16,24,40,.08)` у блока
   фильтров и контейнера таблицы; в тёмной теме затемнения нет (как сейчас). Точное
   значение токена зафиксирует decision.md после апрува.
9. Быстрые кнопки дат («Сегодня» и др.) — активное состояние дата-диапазона показано
   заполненными полями + выделенной нажатой кнопкой.
10. Невыделенные чипы групп и кнопки дат (светлая тема, раунд 5): заливка #f7f9fe
    (значение владельца 25.11.2026), контур — токен `--border` (как у поля поиска);
    disabled «Сбросить даты» = невыделенное с приглушённым текстом; тёмная тема — без изменений.
11. Шапка прототипов (раунд 6): логотип — ассеты текущей реализации KON-135
    (logo_head.svg + logo_wordmark.svg, копии в design/KON-166/), иконка выхода — белая;
    строка заголовков колонок («Кандидат/Совпадение/Рекомендации») в раскрытом блоке
    кандидатов убрана по решению владельца — колонки контента сохранены.
